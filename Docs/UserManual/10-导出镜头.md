# 10 导出镜头

前面几章都是"从 MMD 带东西进来"，这一章反过来：把你在 Unreal 里调好的镜头存回 `.vmd` 文件，带回 MMD 继续用，或者分享给还在用 MMD 的朋友。

## 这个功能是干什么的

在 Unreal 里你可以随意调整镜头：挪机位、改节奏、加运镜。调完之后点一下导出，插件会把整段镜头的最终效果整理成一份 MMD 能直接打开的 `.vmd` 相机文件。也就是说：**Unreal 里怎么调，MMD 里就怎么放。**

## 导出步骤
![镜头导出](DocPic/Camera_Out1.jpg)
1. 在内容浏览器里**双击**之前导入（或在 Unreal 里制作）的那段镜头序列，会打开一个带时间轴的编辑窗口。
2. 看窗口上方的工具栏，找到一个写着 **M2U** 的按钮（相机小图标）。找不到的话先把鼠标悬停在工具栏图标上看看提示文字。
3. 点它，弹出导出设置窗口。
4. 按下面的说明设置选项。
5. 点**导出 VMD**，选好保存位置和文件名（默认是 `序列名_Camera.vmd`）。
6. 完成后会弹出一个结果报告。

## 导出窗口每个选项是什么意思
![镜头导出设置](DocPic/Camera_Out2.jpg)
先说一个背景：MMD 记录镜头的方式是"围绕哪个参考点、离它多远、转到什么角度"。而 Unreal 里的镜头是自由的。所以导出时最重要的一件事，就是告诉插件**这个参考点在哪**。

### 相机原点 Binding（参考点是谁）

下拉列表会列出这段镜头序列里出现的东西：

- **选你的角色**（最常用）：镜头会以角色为参照导出，回到 MMD 里打开时，镜头和角色的相对关系与原作一致。
- **未选择（手动坐标）**：不选任何对象，自己在下面的 X、Y、Z 输入框里填一个参考点的位置。

### 原点来源 / Component・骨骼・Socket

选定参考对象后，进一步指定用它身上的哪个部位当参考点：

- **Actor 变换**：用整个物体的位置。最简单，一般够用。
- **组件变换 / 骨骼 Socket 变换**：让参考点跟着模型身上的某根骨骼走。下面的名字框默认填的是 `全ての親`，也就是模型的总根骨骼，通常不用改。

### 原点评估

- **锁定导出起始帧**：参考点的位置按第一帧那一刻固定下来，之后不再变动。默认选项，大多数情况直接用。
- **逐帧跟随**：参考点每一帧都重新读取位置，适合参考对象本身会在场景里移动的情况。

如果导出后在 MMD 里查看发现镜头和画面对不上，换另一个选项再导一次试试。

### 帧范围

- **当前范围**：导出整段时间轴。
- **自定义范围**：只导出一部分，填起止帧号。比如整段作品只要前半段的镜头，就不用把后半段一起带走。

### 高级（默认收起，不用管）

四个精度数值：容差越小，导出的关键帧越多、还原越精细；容差越大，文件越简洁。"普通相机距离"是 MMD 的标准距离值，保持默认即可。不了解就全部不动。

## 结果报告怎么看

导出成功后弹出的报告里有几个数字：

| 数字 | 含义 |
|---|---|
| 稠密采样数 | 插件核对过的画面数量 |
| 镜头数 | 识别出的机位切换次数 |
| 稀疏 VMD 关键帧数 | 最终写进文件的镜头关键点数量 |
| 最大位置 / 旋转 / 视角误差 | 导出结果与原画面的最大偏差 |

三个误差数字都非常小就是成功。文件里偶尔会有警告条目，说明个别地方做了取舍，一般不影响使用。

## 常见问题

### 导出镜头时找不到 M2U 菜单

先在 Sequencer 中打开要导出的 Level Sequence，并确认时间轴里存在 **Camera Cut**。如果只是想导出角色动作，请看[09 导出角色动作 VMD](09-导出角色动作.md)。
