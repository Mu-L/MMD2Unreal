# 05-2 手臂约束修正

角色动作已经导入后，如果出现手臂或手掌穿进身体、头部、腿部，或者左右手臂互相穿过去的情况，可以使用 **手臂约束修正** 自动减少这些穿模。

这个功能主要处理：

- 上臂或前臂穿进躯干；
- 手掌穿进胸口、颈部、头部或腿部；
- 双臂交叉时彼此穿透；
- 动作较快、手臂一下进入身体内部时的明显穿模。

它只修正需要避让的手臂姿态，不会替代原动作，也不是头发、裙摆一类的物理解算。

## 默认是否开启

导入 **角色** PMX 时，**Rig → 手臂约束修正** 默认开启。

导入 **场景** PMX 时，这个选项默认关闭，因为场景通常不需要角色手臂修正。

对于大多数角色，建议先保持默认开启，播放动作后再决定是否需要调节。

## 已经导入的模型怎么开启

如果模型是在旧版本中导入的，或者当时没有生成这个节点，可以重新导入 PMX：

1. 对模型执行 Reimport。
2. 勾选 **覆盖已有 Post Process AnimBP**。
3. 确认它下面的 **手臂约束修正** 已勾选。
4. 完成重新导入。

**手臂约束修正是 Post Process AnimBP 的附属选项。** 如果没有勾选 **覆盖已有 Post Process AnimBP**，插件不会修改现有 ABP，也不会单独追加这个功能。

## 在哪里调节

在 Content Browser 中找到：

`ABP_Post_<模型名>`

打开它的 **AnimGraph**，可以看到 **M2U Arm Constraint Correction（手臂约束修正）** 节点。正常情况下，它位于 MMD 姿态处理之后、KawaiiPhysics 之前。

自动生成的周边节点用于保持不同 PMX 模型自身的手臂、追加骨骼和 IK 关系。正常使用时不要删除、跳过或自行重排这些自动生成节点。

节点上的 **Alpha** 为总强度：

- `1.0`：完整启用；
- `0.0`：关闭修正；
- 中间值：降低整体修正强度。

一般保持 `1.0` 即可。

## 最常用的参数

大多数模型不需要修改参数。出现特殊动作时，优先按下面几项调整。

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| **Contact Margin (cm)** | `0.8` | 手臂与阻挡表面之间保留的最小间距。数值越大，手臂离身体越远。 |
| **Avoidance Soft Zone (cm)** | `0.65` | 接近穿模前，修正开始逐渐介入的范围。越小越尊重原动作，越大越早开始避让。 |
| **Crossing Guard Distance (cm)** | `32` | 一次修正允许把手肘或手腕从原动作位置移开的最大距离。快速动作仍直接穿过去时优先提高它。 |
| **Solver Iterations** | `4` | 每帧尝试修正的次数。通常不要修改。 |
| **Pose Preservation Weight** | `0.35` | 保留原动作姿态的倾向。数值越高，正常动作越不容易被改变。 |
| **Max Elbow Bend (deg)** | `155°` | 修正时允许的最大肘部弯曲程度，用于减少翻肘和过度折叠。 |
| **Upper Arm Probe Start** | `0.32` | 从肩膀往下有多少比例不参与上臂碰撞，避免正常的肩膀连接处被当成穿模。 |
| **Hand Rotation Follow** | `0.0` | 手腕朝向跟随避让结果的程度。`0` 最能保持原动作手型，通常建议保持默认。 |
| **Cross Arm Response Scale** | `0.65` | 左右手臂互相避让的整体强度。数值越低，主动交叉时越容易柔和地让位；不影响手臂与身体的碰撞修正。 |
| **Cross Arm Soft Zone (cm)** | `3.0` | 左右手臂接触前开始逐渐介入的范围，也会让接近重合时的推开方向更平滑。 |
| **Cross Arm Priority** | `0.2` | 左右手臂互撞时哪一侧更接近原动作，范围为 `-1` 到 `1`：负值偏向保护左臂，`0` 平均分配，正值偏向保护右臂。 |

左右手臂组中还可以看到 **Upper Arm Radius / Forearm Radius / Hand Radius**。这些尺寸在导入时会根据模型自动准备，通常不需要手动设置。

如果只是手掌仍容易穿模，可以小幅提高对应一侧的 **Hand Radius**，建议一次增加约 `10%～20%`，不要直接放大很多，否则会让手还没靠近身体就提前避让。

## 各碰撞开关

节点中可以单独关闭某类检测：

- **Upper Arm Collision**：上臂；
- **Forearm Collision**：前臂；
- **Hand Collision**：手部；
- **Cross Arm Collision**：左右手臂互相阻挡；
- **Neck Collision**：颈部；
- **Head Collision**：头部；
- **Leg Collision**：腿部。

默认设置适合大部分角色。排查特殊模型时，可以暂时关闭某一项观察问题是否消失，但不建议为了一个动作长期关闭大范围碰撞。

## 使用 Debug Draw 看修正范围

如果不知道是哪一个碰撞范围在影响动作，可以在节点中打开 **Debug Draw**。

播放或拖动动画时会显示调试线框：

- **红色**：身体、颈部、头部和腿部的实际阻挡范围；
- **黄色**：开始触发避让的外侧范围；
- **橙色**：原始动画中的手臂路径；
- **绿色**：修正后参与检测的上臂、前臂范围；
- **青蓝色球体**：手部检测范围；
- **灰色手球**：当前关闭了 Hand Collision。

调试图形会正常被模型遮挡，因此从不同角度查看会更容易判断空间关系。

**Debug Draw Alpha** 可以控制所有调试图形的透明度。只用于查看问题，最终制作时可以关闭 Debug Draw。

## 常见问题怎么调

### 手臂到某个位置还是会突然穿过去

先提高 **Crossing Guard Distance**。

例如：

`32 → 40 → 50`

逐步增加，直到快速或较深的动作能够被挡住。数值过大会允许姿态离原动作太远，所以不建议一开始就拉满。

### 没有明显穿模，但正常动作也被改了很多

按这个顺序尝试：

1. 提高 **Pose Preservation Weight**，例如 `0.35 → 0.45`；
2. 适当减小 **Avoidance Soft Zone**，例如 `0.65 → 0.4`；
3. 如果主要发生在肩膀附近，可小幅提高 **Upper Arm Probe Start**。

每次只改一项，然后重新播放观察。

### 手肘折得太狠或出现翻肘感

降低 **Max Elbow Bend**，例如：

`155° → 145°` 或 `135°`

同时建议保持 **Hand Rotation Follow = 0**，避免手腕跟着前臂修正一起产生明显扭转。

### 手掌还是容易进入身体

打开 **Debug Draw**，先确认青蓝色的 Hand Sphere 是否覆盖了需要保护的手掌区域。

如果球体明显太小，可以小幅提高对应手臂的 **Hand Radius**。如果球体已经足够大，但仍会在快速动作中穿过去，则应提高 **Crossing Guard Distance**，而不是继续无限放大手球。

### 双手交叉时互相穿透

确认 **Cross Arm Collision** 保持开启。在动作仍保持正常左右顺序时，左右两侧会按 **Cross Arm Priority** 同时做出避让，而不是只固定其中一只手；如果原动作明确要求双臂交换左右顺序，系统会在交叉处平滑减弱这项避让，优先跟随原动作以避免抖动。手臂与身体的碰撞仍会继续生效。

## 和 MMD IK、KawaiiPhysics 的关系

手臂约束修正会在模型自身的 MMD 姿态关系处理完成后工作，并在 KawaiiPhysics 之前完成手臂避让。

因此：

- 不需要为了使用它关闭 MMD IK；
- 不需要调整 KawaiiPhysics 才能让手臂修正生效；
- 某些带有额外腕轴、肘轴、捩骨或辅助骨的模型，也会继续按照模型自己的关系更新；
- 不要删除自动生成的前后转换和 MMD 约束节点。

如果只想临时比较开启前后的效果，直接调整 **Arm Constraint Correction → Alpha** 最安全。

## 需要知道的边界

手臂约束修正主要用于减少常见动作中的角色自身穿模，并尽量保留原动画。

非常极端的动作，例如单帧内从身体一侧直接跳到另一侧、原动作本身严重折叠，仍可能需要提高 **Crossing Guard Distance** 或直接修一下动作关键帧。

它也不会处理角色与其他角色之间的碰撞。
