# 08 使用 Rig 编辑已有的动作

这一章介绍如何保留已有的 MMD 动作，把新的调整作为一层 Control Rig 修正叠加到原动作上。推荐使用插件生成的 `CRMMD_模型名`，在 Sequencer 中以 **Layered Control Rig** 方式追加控制绑定。

这种做法的好处是：原来的 Animation Sequence 继续作为底层动作，新的手臂、身体、手指或表情修改单独放在上层。你可以反复调整上层控制器，不必先把原动作烘焙或改写，也不会把整段动作的原始关键帧打乱。

## 什么时候使用这一章

- 已经导入了一段 VMD，并得到对应的 Animation Sequence。
- 只想修正某几个姿势，例如抬高手臂、修脚底穿地、改变视线或调整表情。
- 想保留原舞蹈的节奏和大部分动作，只在指定帧追加少量修改。

如果是从零创作，没有底层动作，请看[07 使用 Rig 创作动作](07-使用Rig创作动作.md)。

## 开始之前

- 已按[导入角色动作](05-导入角色动作.md)导入 VMD 动作，并选择了与角色匹配的目标 Skeletal Mesh。
- 已准备一个 Level Sequence，并把同一个 MMD 角色放入关卡和 Sequencer。
- 内容浏览器中能找到与该模型对应的 `CRMMD_模型名` Control Rig。导入模型时必须开启**创建 Rig 绑定（Create Rig Binding）**。

## 一、把已有动作放到底层

1. 打开或新建一个 Level Sequence，把 MMD 角色从 World Outliner 加入 Sequencer。
2. 在角色的 **Skeletal Mesh** 轨道上添加 **Animation** 轨道；也可以直接把已经导入的 Animation Sequence 从内容浏览器拖到 Skeletal Mesh 轨道上。
3. 在 Animation 片段中选择要使用的动作，设置片段的开始帧和结束帧。先播放确认原动作本身已经正常，脚、手和表情都能随时间变化。
4. 这一条 Animation 轨道就是底层。后面添加的 Control Rig 修正必须放在**同一个角色绑定**下，不要另建一个角色或把 Rig 加到相机绑定上。

## 二、以分层方式添加 `CRMMD_`

推荐在添加时直接选择分层方式：

1. 选中同一个角色的 **Skeletal Mesh** 轨道，点击 **+ Track**。
2. 选择 **Control Rig > Layered**，然后选择本模型对应的 `CRMMD_模型名`。如果菜单先让你选择 Rig，再提供分层选项，勾选 **Layered** 后确认。
![添加分层 Control Rig](DocPic/Controlrig_Add.jpg)
3. 如果你的菜单没有直接显示 **Layered**，先使用 **Control Rig > Control Rig Classes** 添加 `CRMMD_模型名`，然后在 Sequencer 左侧的 Control Rig 轨道上点击右键，选择 **Convert To Layered**。
4. 确认 Control Rig 片段和 Animation 片段在时间上重叠，至少覆盖你想修正的帧。Control Rig 片段只覆盖修正区间时，区间外会继续使用原来的底层动作。
5. 展开 Control Rig 轨道，确认能看到 `CRMMD_` 的控制器。插件生成的 `CRMMD_` 已包含让控制器读取当前骨骼动作的反向求解，因此它可以把已有 Animation Sequence 当作输入，再在上面追加调整。

> **判断是否成功分层**：播放头在已有动作上移动时，角色仍然保持原来的舞蹈姿势；你移动一个 `CRMMD_` 控制器时，只在该处产生修正。如果一加 Rig 角色就跳回参考姿势，通常是没有转换为 Layered，或 Control Rig 片段没有和 Animation 片段重叠。

## 三、在原动作上追加修正

### 1. 修正身体和四肢

1. 把播放头移动到需要修改的帧，先观察底层动作在这一帧的姿势。
2. 在 Control Rig 轨道中选择需要修改的 `CRMMD_` 控制器。身体常用 `CTRL_Chest`、`CTRL_UpperChest`、`CTRL_Pelvis`、`CTRL_Neck` 和 `CTRL_Head`。
3. 手臂优先使用 `CTRL_UpperArm_L/R`、`CTRL_LowerArm_L/R` 和 `CTRL_Hand_L/R`，按上臂、前臂、手的顺序逐段小幅旋转。这样只修正需要的骨骼，不会像重新制作整段动作一样覆盖所有细节。
4. 调整到满意的姿势后，对修改过的控制器按 `S` 或点击钥匙按钮。只给真正需要改的控制器打帧，不要把所有控制器都一次性打帧。
5. 移动到下一处需要修正的帧，重复调整和打帧。相邻关键帧之间会自动插值；需要保持修正时，在保持区间的开始和结束帧都打上相同的修正。

### 2. 修正脚、手指和视线

- 脚底穿地时，可以在 `CTRL_LegIK_L/R` 或对应的腿脚控制器上做小幅修正；如果只是脚尖方向不对，再使用 `CTRL_Toe_L/R`。
- 手型不对时，只选需要的 `CTRL_Thumb_*`、`CTRL_Index_*` 等手指控制器打帧，不要重新给整只手臂打满关键帧。
- 视线不对时，使用 `CTRL_Eye_L` 和 `CTRL_Eye_R` 调整眼睛方向，然后在面部控制器通道上打帧。

### 3. 追加表情

1. 展开 `CTRL_Face_` 面部控制器组，找到眼睛、嘴、眉毛等区域的滑块。
2. 在需要改变表情的帧调整滑块，并点击通道旁的钥匙按钮记录数值；表情通常用 0 到 1 的范围控制。
3. 如果只想让表情变淡，可以在相邻帧把滑块设为较小值；如果要恢复原表情，可以减少上层的修正，或在该段末尾把修正值逐渐回到 0。

## 四、管理分层轨道

### 轨道顺序（Order）

- 只有一条 `CRMMD_` 分层轨道时，通常保留默认设置即可。
- 使用多条 Control Rig 轨道时，在轨道上点击右键可以调整 **Order**。编辑器默认从 100 开始；多条分层轨道应使用不同的顺序，并在播放时确认最后生效的修正符合预期。
- 如果后加的一条普通（非 Layered）Control Rig 轨道把前面的修正覆盖了，优先把它转换为 Layered，或检查各条轨道的 Order。底层 Animation 片段应保持不动，修正尽量放在分层轨道中。

### 修正强度（Weight）

- 在 Control Rig 轨道上点击右键并启用 **Weight**，可以给整层修正设置权重。
- 权重为 0 时相当于暂时关闭这层，权重逐渐增加时可以让修正平滑出现；这适合让一个姿势修正慢慢加入，而不是突然跳变。
- 权重的关键帧也保存在 Level Sequence 中。若只想关闭某次试验，优先把权重降为 0，不要删除整条轨道。

### 只编辑一部分动作

把 Control Rig 片段的起止范围缩到需要修正的区间。区间外仍然由原来的 Animation Sequence 播放，便于只修正一个副歌动作、一个落脚点或一段表情。

## 五、曲线和回退

1. 展开 `CRMMD_` 轨道，选择某个控制器的平移、旋转或表情通道，在 Curve Editor 中调整插值和切线。
2. 如果修正过度，先撤销最近的控制器调整，或删除该控制器在当前区间的钥匙；不要删除底层 Animation 片段。
3. 想比较原动作和修正结果时，可以暂时把分层 Control Rig 片段禁用，或者把 Weight 设为 0。确认无误后重新启用。
4. 想把最终结果固化成一个新的动画资产时，可以在角色的 Skeletal Mesh 轨道上使用 **Bake Animation Sequence**；但只是为了导出 VMD 时不必烘焙，直接使用当前 Sequencer 就能导出最终姿势。

## 六、预览、保存和导出

1. 从修正区间前开始播放，确认原动作的节奏没有被改变，修正只在预期的帧生效。
2. 特别检查手臂是否突然翻转、脚是否穿地、面部滑块是否跳变，以及修正区间的首尾是否平滑。
3. 保存 Level Sequence。上层 `CRMMD_` 的控制器关键帧和底层 Animation Sequence 会一起参与 Sequencer 的最终评估。
4. 想把这段组合后的角色动作带回 MMD 时，继续看[09 导出角色动作 VMD](09-导出角色动作.md)。导出窗口选择当前 Sequencer 作为来源，插件会读取底层动作加上分层 Control Rig 后的**最终作者层骨骼和表情**；Post Process 中的 PMX CCD、追加变形与物理不会作为普通 VMD 骨轨再次烘焙。

这套模型控制器的自动绑定算法是`RedialC`倾注了大量心血的产物，如果你使用了这套rig产出了动作数据并觉得好用,希望能够标注使用工具让更多人使用上现代化的MMD动作K帧流程！

## 常见问题

### 加入 `CRMMD_` 后原动作不见了

检查 Control Rig 轨道是否通过 **Convert To Layered** 转换，或者重新从 **Control Rig > Layered** 添加。还要检查 Control Rig 片段是否和 Animation 片段重叠，以及是否误用了普通的非分层轨道。

### 分层后控制器位置与角色不一致

确认使用的是与当前 Skeletal Mesh 配套的 `CRMMD_模型名`，并且播放头位于 Animation 片段和 Control Rig 片段的共同范围内。刚添加轨道后先移动播放头到已有动作的中间帧，再选择控制器观察它是否跟随角色。

### 只想改手臂，却把全身动作覆盖了

删除不需要的控制器关键帧，只保留上臂、前臂和手的修正；不要给 Root、Center、Pelvis 等整体控制器添加无关关键帧。分层编辑的重点就是让上层只记录“需要改变的部分”。
