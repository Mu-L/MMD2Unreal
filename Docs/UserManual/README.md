# MMD2Unreal 用户手册

这份手册写给想要延续MMD社区生态的同时想要使用更加现代化软件工具的朋友。

不需要任何编程知识，只需要你了解MMD以及一个愿意接触UE引擎的心态。

很简单的！ 跟着一步一步点就能完成。

## 当前支持环境

- Unreal Engine 5.8（如果可以的话，请尽量从Epic启动器下载安装）
- Windows x86电脑、Intel/M系列芯片 Mac电脑

- 不支持 Windows ARM 电脑、华为鸿蒙电脑，以及其他无法原生启动 Unreal Engine 的设备。

## 一分钟了解整个流程

1. **装插件**：从发布页下载，放进项目的 Plugins 文件夹，打开项目启用它。
2. **拖模型**：把 `.pmx` 文件直接拖进 Unreal 底部的内容浏览器，点一下导入，模型就出现了。支持角色模型和场景模型。
3. （可选）**调姿态和物理**：如果导入时勾选了 **启用物理**，先检查模型姿态，再在 `ABP_Post_` 的 KawaiiPhysics 节点中选择碰撞组并调整物理效果。
4. （可选）**调材质**：如果需要改变模型外观，可以打开对应的材质实例，调整已暴露的材质属性。
5. **拖动作**：把跳舞用的 `.vmd` 文件也拖进去，选好刚才导入MMD的模特。
6. **拖镜头**：把运镜用的 `.vmd` 文件拖进去，你就得到了一段可以在 Unreal 里播放的镜头序列。
7. （可选）**用 Rig 调动作**：在 Sequencer 里用 `CR_` / `CRMMD_` Control Rig 从零创作动作，或把 `CRMMD_` 作为分层控制绑定叠加到已有动作上。
8. （可选）**带回去**：在 Unreal 里调完角色动作或镜头后，可以分别导出为 `.vmd` 文件，拿回 MMD 继续用。

整个导入过程就像往文件夹里拖文件一样简单：**会拖拽，就会用这个插件。**

导入之后的步骤插件都做到无限接近UE原生级的体验，**没有额外的单独窗口需要开启。**

## 使用前的一点心理准备

- 手册里的每一步都只涉及 拖文件、勾选项、点按钮 这三种动作。
- 导入后项目里会出现一些名字奇怪的小文件（比如以 `IKR_`、`ABP_Post_`、`RM_` 开头的），它们是插件自动准备的资产；其中 `RM_` 资产保存 PMX 模型的注释信息，已经解决了传统流程的99%的步骤，如果需要调整也只会非常简单的。
- 遇到任何看不懂的选项，保持默认值就是最安全的选择。
