# 04 M2U 材质调节

本章介绍导入 MMD 模型后，如何理解和调整 M2U 材质。

## 先理解：M2U 材质的定位

插件当前提供的 M2U 预设材质，以材质函数 `MF_MMD_RedialC` 为基础，是一个偏基础、面向 MMD 用户的过渡方案。它保留了颜色、贴图、粗糙度、法线、发光和 MMD `SPA/SPH` 球面贴图等常用调节入口，让还不熟悉 Unreal Engine 的用户可以先用接近 Ray-MMD 的思路完成模型迁移和外观调整。

这套预设的目标是提供一个可靠的起点，而不是完整复刻 Ray-MMD，也不是 Unreal 材质能力的上限。它不应成为封闭的“黑盒”，也不应让人误以为 Unreal 的材质系统只能这样使用；当你积累了自己的审美和使用习惯后，可以继续学习 UE 的材质系统并制作属于自己的材质母球（在 Unreal Engine 中通常称为母材质）。

## 推荐的入门调节顺序

第一次使用时，不需要先理解所有材质资产的命名。先打开最终的 `Mi_<模型名>_<材质名>`；在 Details 面板中，只有勾选参数左侧的覆盖框后，改动才会写入这个材质实例。按照下面的顺序调整：

1. 确认 `Diffuse` 主贴图是否正确。导入模型后，这张贴图通常已经由插件自动绑定。
2. 使用 `DiffuseColor` 做整体色调修正，例如调整衣服、头发或皮肤的颜色。
3. 使用 `Roughness` 调整表面是更光滑还是更哑光。
4. 如果模型使用了 MMD 的 SPA/SPH，再检查 `Sphere` 以及对应的加算/乘算强度。正常通过 PMX 导入时，这些值通常会自动设置。
5. 最后再尝试 `Normal`、`Emissive`、`RimLight` 和透明参数。
6. 点击 **Save**，并在模型预览或关卡中检查最终效果。

如果在 `Mi_` 中找不到需要的选项，先确认当前材质实例的 Parent，再检查父材质是否提供了对应参数。每次调整后点击 **Save**，并在模型预览或关卡中查看效果。不要为了修改一个材质槽就直接改共享的 `MF_MMD_RedialC`；共享函数的改动会影响所有引用它的 `MS_`。

## 当前预设的可调节属性

下面按材质实例 Details 面板的分组列出当前实际可见的参数。名称与面板保持一致；建议先从 `Diffuse`、`DiffuseColor` 和 `Roughness` 开始。`*Setting` 是对应贴图的坐标高级设置，没有明确需求时保持默认即可。

### `0.Debug`

| 参数 | 什么时候用 |
|---|---|
| `Z-Fighting` | 两个表面重叠而出现闪烁、抖动时才调整。建议从接近 `0` 的数值开始，小幅尝试。 |

### `1.Diffuse`

| 参数 | 什么时候用 |
|---|---|
| `Diffuse` | 主颜色贴图。导入模型后通常已自动绑定。 |
| `DiffuseColor` | 整体调色的首选；例如快速改变衣服、头发或皮肤的颜色。默认白色表示不额外染色。 |
| `DiffuseColorProfile` | 想进一步改变整体色彩观感时再用；普通调色优先使用 `DiffuseColor`。 |
| `DiffuselSetting` | 主颜色贴图的坐标高级设置。 |

### `2.Roughness`

| 参数 | 什么时候用 |
|---|---|
| `Roughness` | 控制表面偏光滑还是偏哑光。基础预设值约为 `0.6`；先调这个，再考虑粗糙度贴图。 |
| `RoughnessMap` | 准备了对应粗糙度贴图时使用。 |
| `EnableRoughnessMap` | 要让 `RoughnessMap` 生效时开启；默认关闭。 |
| `RoughnesslSetting` | 粗糙度贴图的坐标高级设置。 |
| `Anisotropy` | 各向异性外观的进阶调节。普通 MMD 材质通常不需要改动。 |

### `3.Specular`

| 参数 | 什么时候用 |
|---|---|
| `Specular` | 高光强度。基础预设值约为 `0.1`；不熟悉时保持默认即可。 |
| `Metallic` | 金属度。布料、皮肤和塑料通常使用较低值。 |
| `MetallicMap` | 准备了对应金属度贴图时使用。 |
| `EnableMetallicMap` | 要让 `MetallicMap` 生效时开启；默认关闭。 |
| `MetalSetting` | 金属度贴图的坐标高级设置。 |

### `4.Emissive`

| 参数 | 什么时候用 |
|---|---|
| `Emissive` | 自发光贴图。适合眼睛、饰品、灯光或特殊效果。 |
| `EmissiveColor` | 调整自发光的颜色与强度。普通底色不建议完全依赖自发光。 |
| `RimLight` | 边缘光外观的风格化调节。 |
| `RimLightSoftness` | 调整边缘光的柔和程度；基础预设值约为 `0.25`。 |

### `5.Normal`

| 参数 | 什么时候用 |
|---|---|
| `Normal` | 法线贴图。没有额外法线贴图时保持默认即可。 |
| `NormalIntensity` | 调整法线细节强度，基础预设值为 `1.0`。建议小幅改动，避免细节过度。 |
| `NormalSetting` | 法线贴图的坐标高级设置。 |

### `6.MMD SPA/SPH`

| 参数 | 什么时候用 |
|---|---|
| `Sphere` | MMD 的 SPA/SPH 球面贴图。PMX 材质设置了球面贴图时通常会自动绑定。 |
| `SphereAddStrength` | 调整 SPA（加算）球面贴图的影响。PMX 导入会按球面贴图模式自动设置。 |
| `SphereMulStrength` | 调整 SPH（乘算）球面贴图的影响。PMX 导入会按球面贴图模式自动设置。 |

### `7.Opacity`

| 参数 | 什么时候用 |
|---|---|
| `Opacity` | 整体透明度，基础预设值为 `1.0`。 |
| `OpacityGamma` | 调整透明过渡的观感；基础预设值为 `1.0`。边缘过硬或过软时再尝试。 |
| `EnableShadow` | 控制透明材质是否参与阴影处理；默认开启。 |

## 用自己的材质母球（母材质）快速替换整个模型

本文所说的“材质母球”，在 UE 中对应可被材质实例继承的母材质资产，例如 `M_` 或 `MS_`。当你已经形成自己的调节习惯后，可以准备一套自己的母材质，并通过模型级材质实例快速替换整套模型的基础外观。这个技巧不需要逐个打开几十个甚至上百个 `Mi_`：

1. 制作或准备一个自己的母材质，例如 `M_MyMmdBase`。可以从现有 `MS_` 复制并继续修改，也可以完全使用自己熟悉的节点结构。
2. 在内容浏览器中找到模型的 `Materials/MotherMat/MSi_<模型名>` 并打开。
3. 在 Details 面板中把它的 **Parent** 换成自己的母材质，保存材质实例。
4. 检查模型预览。所有以 `MSi_<模型名>` 为父级的 `Mi_` 都会沿着新的父级材质更新，整个模型的基础外观就可以快速切换。

为了尽量保留 `Mi_` 中由 PMX 导入的常用设置，自定义母材质应至少优先兼容这些参数名：`Diffuse`、`DiffuseColor`、`Sphere`、`SphereAddStrength` 和 `SphereMulStrength`。如果新母材质没有对应参数，对应的 `Mi_` 覆盖值仍会保留在资产中，但不会驱动新母材质的外观。

这个技巧体现的是 Unreal 的父材质—材质实例继承关系。插件中还有许多类似的小设计，目的不仅是让导入流程更顺手，也希望大家在使用插件的过程中逐渐理解 Unreal 的资产组织、参数继承和批量替换方式。

### 替换材质母球时的重导入提示

当前导入器在同名模型重导入时，会将 `MSi_<模型名>` 的 **Parent** 对齐回该模型的 `MS_<模型名>`。因此，若你为 `MSi_` 指定了自定义母材质，重导入后需要检查并重新设置该 Parent；建议把这一步纳入自己的重导入流程。

## 材质资产的关系：MS、MSi 与 Mi（MI）

完成上面的基础操作后，再回头看资产命名会更容易。下面的关系中，`MS_` 是母材质，`MSi_` 与 `Mi_` 都是材质实例；`MF_` 是材质函数，不是某个材质槽的父材质，也不把它称为母材质。导入并勾选 **创建材质** 后，一个模型的材质通常会形成下面的父子关系：

```text
Mi_<模型名>_<材质名>       最终材质实例：对应一个 PMX 材质槽
└─ MSi_<模型名>            模型级材质实例：所有 Mi_ 共用的中间层
   └─ MS_<模型名>          模型级母材质：这个模型的基础材质
      └─ MF_MMD_RedialC    共享的 MMD 基础材质函数
```

- `Mi_<模型名>_<材质名>`：每个 PMX 材质槽对应的最终材质实例。单独调整某一块衣服、头发或其他材质时，通常打开这一层。
- `MSi_<模型名>`：模型级材质实例，是 `MS_` 与所有最终 `Mi_` 之间的公共层。替换它的 **Parent**，就能为整个模型切换母材质。
- `MS_<模型名>`：当前模型的母材质。导入器首次创建时，会在其中使用 `MF_MMD_RedialC` 建立基础材质。
- `MF_MMD_RedialC`：多个模型可以共用的基础材质函数。修改它时要注意影响范围。

文档中有时会用 **MI** 泛指 Material Instance（材质实例）。资产的实际命名使用 `Mi_` 和 `MSi_`，大小写和前缀请以内容浏览器中的文件名为准。这些资产通常位于模型导入目录下的 `Materials` 与 `Materials/MotherMat` 文件夹中。

## 什么时候应该离开这套基础材质

当你开始需要复杂的角色皮肤、布料、玻璃、特殊光照、分层材质或项目级性能控制时，可以把 M2U 材质当作参考和过渡层，学习并制作自己的 `M_` 母材质与 `MF_` 材质函数。你仍然可以保留 `Mi_` 的组织方式，也可以利用 `MSi_` 这个模型级替换点，把已经积累好的材质习惯快速应用到整套模型。

M2U 的基础材质是帮助你进入 Unreal 的第一块踏板，不是对 Unreal 材质能力的定义。理解 `MS`、`MSi`、`Mi` 的职责后，你就已经开始使用 Unreal 中很重要的材质继承和批量替换思路了。

## 注意事项

- 修改 `MS_` 或共享的 `MF_MMD_RedialC` 前，先确认影响范围；共享函数的变化可能同时影响多个引用它的 `MS_`。
- 替换 `MSi_` 的 Parent 时，尽量使用参数名兼容的母材质，否则 `Mi_` 中保存的贴图和颜色参数可能无法驱动新材质。
- 如果重新导入同名模型，请重新确认 `MSi_` 的 Parent 是否仍然指向自己的母材质。
