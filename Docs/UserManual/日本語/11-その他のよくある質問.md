# 11 その他のよくある質問

ここには、特定の操作章に分類できない共通の質問を残します。モデル・モーション・カメラ・書き出しの問題は、まず該当章の「よくある問題」を確認してください。

> **お知らせ**：本マニュアルは中国語の原文（正式版）をもとにAIで翻訳したものです。表現が完全に正確ではない場合があります。

## ソースファイルと既存アセット

### モデルやモーションの元ファイルを更新しても、既存アセットが自動更新されない

元のモデルやモーションを更新した後、既存コンテンツをワンクリックで更新する機能はまだありません。新しくインポートし直してください。すでに調整したアセットを上書きしないよう、新しいコンテンツブラウザのフォルダへ入れるのがおすすめです。

### 再インポート前に、すでに調整した内容を残すには

まずプロジェクトを保存し、変更したアセットと場所を記録します。たとえばマテリアルインスタンス、Level Sequence、Control Rigのキー、Physics Asset、`ABP_Post_` です。元ファイルを更新した後は新しいフォルダへインポートし、モデル、骨格、マテリアルスロット、モーションを確認してください。問題がなければ、残したい調整だけを選んで移します。

再インポートは、すべての手動調整を必ず保持する操作ではありません。プラグインが自動生成するアセットはインポート結果に応じて変わることがあります。時間をかけて調整した内容は、戻せるコピーを残しておくと安心です。

## どの章にも当てはまらない問題の調べ方

1. このマニュアルが対象とするUnreal Engineのバージョンを使っているか、`MMD2Unreal` とKawaiiPhysicsの両方が **Edit > Plugins** で有効かを確認します。有効化後はエディタを再起動してください。
2. 問題を1つのモデル、モーション、またはカメラに絞ります。複数のアセットを同時に変更しないでください。
3. Unrealの **Output Log** を確認します。最終的な画面だけでなく、問題が起きたときの警告やエラーを記録してください。
4. 同名または古いアセットが干渉する可能性がある場合は、新しいコンテンツブラウザのフォルダへ再インポートして結果を比較します。

## 問い合わせ時に用意する情報

情報がそろっているほど、問題を再現して判断しやすくなります。次の内容を添えてください。

- Unreal Engine、MMD2Unreal、KawaiiPhysicsのバージョン；
- インポートから問題が起きるまでの最短手順；
- 関係するOutput Logの警告またはエラー文；
- 問題が分かるスクリーンショット、短い動画、または共有可能な最小PMX/VMDサンプル；
- すでに試した対処方法。

プライベートなパス、アカウント情報、無関係なプロジェクト内容を含むログ全体は送らないでください。問題が起きた時間の近くの部分だけを抜き出せば十分です。

## まずAIツールで主体的に学び、問題を整理する

現在のAIツールは、UEの理解、ログの読み取り、再現手順の整理、公式資料の検索に役立ちます。問題に出会ったら、ChatGPT、Claude、通義千問（Qwen）、DeepSeekなどのチャットツール、またはCodex、Claude CodeなどのAgent Harnessツールを使い、次のことを試してください。

- Output Logの重要な情報を時刻・警告・エラーごとに整理する；
- 曖昧な現象を再現可能な手順にする；
- Unreal、KawaiiPhysics、MMDデータ形式に関する資料を探す；
- 現在の設定とチュートリアルの期待結果を比べ、確認済みのことと未確認のことを分ける。

AIの提案も、実際のプロジェクトに照らして判断する必要があります。重要なアセットに未検証の操作を一括適用しないでください。まずコピーまたは新しいフォルダで小さく確認してから、採用するか決めます。

## 曖昧な質問はできるだけ避ける

「インポートが壊れた」「物理がおかしい」「モデルが爆発した」だけでは、誰にとっても正確な判断が難しくなります。良い質問には、達成したい結果、実際に見えた結果、どの手順から起きたか、安定して再現するか、すでに試したことを含めます。問題を絞り、根拠を示すことは、関係のないファイルを大量に送るより役立つことが多いです。

## Unrealを次の成長の足場にする

MMDからUnrealへ進むと、より多くのツール、概念、自分で判断する選択肢に触れることになります。主体的な学習、調査、探索が必要になりますが、創作の力をさらに高める機会でもあります。

このプラグインとUnrealを使い、解決した問題を少しずつ自分の方法にしてください。アイデアをより自由に形にし、ほかでも活かせる技術を身に付け、これからの創作、仕事、生活により多くの可能性を作っていきましょう。
