# 07 Rigでモーションを作成する

この章では、UnrealのSequencerでMMDモデルのモーションをゼロから作成する方法を説明します。本プラグインが生成する `CR_` または `CRMMD_` のControl Rigをキャラクターバインディングに追加し、ビューポートでポーズを作ってキーを打つ方法がおすすめです。

すでにVMDモーションがあり、元の動きを一部だけ修正したい場合は、次の[08 既存モーションをRigで編集する](08-既存モーションをRigで編集.md)を読んでください。

> **おすすめの使い分け**：全身のポーズをすばやく作り、手をIKで動かしたい場合は `CR_モデル名` を使います。MMDと同じように上腕・前腕・手を直接回したい場合は `CRMMD_モデル名` を使います。

## 始める前に

- [モデルのインポート](02-モデルのインポート.md)に従ってPMXモデルをインポート済みであること。
- モデルのインポート時に **Rigバインディングを作成（Create Rig Binding）** をオンにしていること。インポート後、モデルのフォルダまたはコンテンツブラウザに `CR_` と `CRMMD_` で始まる2つのControl Rigアセットが表示されます。
- これらのアセットが見つからない場合は、**Rigバインディングを作成**をオンにしてモデルをもう一度インポートしてください。同名保護を避けるため、新しい空のフォルダを使うのがおすすめです。
- レベルと、そこへ配置できるMMDキャラクターがあること。

## 1. Level Sequenceを作成してキャラクターを追加する

1. コンテンツブラウザで **Add** をクリックし、Cinematicsカテゴリから **Level Sequence** を作成します。`Dance_Rig` のように分かりやすい名前を付けます。
2. Level SequenceをダブルクリックしてSequencerで開きます。
3. コンテンツブラウザからMMDキャラクターをレベルへドラッグし、World OutlinerからそのキャラクターをSequencerへドラッグします。キャラクターを選択してSequencerの **Actor to Sequencer** を使っても同じ結果になります。
4. Sequencerでキャラクターバインディングを展開し、キャラクターの **Skeletal Mesh** トラックがあることを確認します。Control Rigはカメラや別のActorではなく、このキャラクターバインディングに追加します。
5. Sequencer上部で再生範囲を設定します。MMDのフレーム番号で作業する場合は、シーケンスの表示レートを **30 FPS** にするのがおすすめです。30フレームがMMDの1秒に相当します。VMD書き出しもMMDの30 FPS時間基準で処理されます。

## 2. キャラクターにControl Rigを追加する

1. キャラクターの **Skeletal Mesh** トラックを選択し、右側の **+ Track** をクリックします。
2. **Control Rig > Control Rig Classes** を選びます。
3. このモデルに対応する `CR_モデル名` または `CRMMD_モデル名` を選択します。別モデル用のRigを選ばないでください。スケルトンが一致しないと、Rigが一覧に出なかったり、正しくキャラクターを動かせなかったりします。
![Control Rig](../DocPic/Controlrig.jpg)
4. SequencerにControl RigトラックとControl Rigセクションが追加されます。展開するとアニメーション可能なコントロールが表示されます。リストでコントロールを選ぶとビューポートでも選択され、ビューポートで選ぶとSequencer上の該当コントロールへ移動します。
5. コントロールが見えない場合は、Control Rigトラックを展開してコントロールを1つ選び、ビューポートの表示をキャラクターへ移します。また、トラック左側の目のアイコンでRigを非表示にしていないか確認します。

> **初回使用時の注意：** Control Rigは、再度入った後に自動でコンパイルを完了するようになりました。Rigを初めて追加したときにコントロールが効かない場合は、対応する `CR_` / `CRMMD_` アセットを一度開くか、レベルビューポートの **Play** ボタンを一度クリックして起動してください。再生を終了した後もControl Rigはコンパイル済みの状態を維持するため、この操作を繰り返す必要はありません。

### `CR_` と `CRMMD_` の選び方

| Rigアセット | 操作方法 | よく使うコントロール | おすすめ |
|---|---|---|---|
| `CR_モデル名` | IKで手足をすばやくポーズする | `CTRL_HandIK_L/R`、`CTRL_ElbowPole_L/R`、`CTRL_LegIK_L/R`、`CTRL_Toe_L/R` | 新しいダンス、歩き、立ちポーズをゼロから作るとき |
| `CRMMD_モデル名` | MMD風にFKの各部を直接回す | `CTRL_UpperArm_L/R`、`CTRL_LowerArm_L/R`、`CTRL_Hand_L/R` | 腕を各部ごとに正確に調整したいとき、MMDの操作に慣れているとき |

どちらのRigにも、体、頭、目、指、脚・足、顔のコントロールがあります。左右のコントロール名は通常 `_L` と `_R` で終わります。

このモデルコントローラーの自動バインディングアルゴリズムは、`RedialC`が多大な努力を注いで作り上げたものです。このRigでモーションデータを作成し、便利だと感じた場合は、ツール名をクレジットして、より多くの人に現代的なMMDモーションのキー打ち方法を知ってもらえるようにしてください。

Sequencerでのキー打ち方法について詳しく知りたい場合は、Unreal Engineの動画チュートリアルや公式マニュアルを参照してください。使い方にはそれぞれの習慣があるため、このマニュアルの後半でも基本だけを説明し、細部には踏み込みません。

## 3. タイムラインで自由にキーを打つ

### 1. 開始ポーズを作る

1. 再生ヘッドをモーションの開始フレーム（通常は0フレーム）へ移動します。
2. ビューポートで使いたいコントロールを選び、移動・回転ツールでポーズを作ります。SequencerやDetailsパネルに数値を直接入力しても構いません。
3. 胴体、両手、両足など、同時に記録したいコントロールを複数選択します。
4. 体の変形コントロールでは `S` を押すか、Sequencerのキーアイコンをクリックしてキーを追加します。トラックの下にコントロールのチャンネルとキーが表示されます。

### 2. 後のフレームでポーズを変える

1. 再生ヘッドを次の重要なポーズへ移動します。例えば15、30、45フレームなどです。
2. コントロールを移動または回転し、もう一度 `S` を押すかキーアイコンをクリックします。
3. 再生ヘッドを移動し、コントロールを変更してキーを打つ作業を続けます。Sequencerは隣り合うキーの間を自動補間します。キーが少ないほど滑らかになり、キーが多いほど指定ポーズを正確に保持できます。
4. ポーズを一定時間保持したい場合は、保持区間の開始と終了の両方でキーを打ちます。開始フレームだけにキーを打たないでください。
5. 複数のコントロールを同時に直す場合は、キーを打つ前にまとめて選択します。胴体・手・足の一部だけがキーになって姿勢が崩れるのを防げます。

### 3. 腕と脚の操作例

- `CR_` では `CTRL_HandIK_L/R` を動かして手の位置を決め、`CTRL_ElbowPole_L/R` を動かして肘の向きを調整し、最後に手のコントロールを回します。肘が突然反対側へ折れる場合は、Poleコントロールの位置を見直します。
- `CRMMD_` では `CTRL_UpperArm_*`、`CTRL_LowerArm_*`、`CTRL_Hand_*` を上腕、前腕、手の順で回します。MMDの上腕・下腕・手首ボーンを直接回す操作に近い方法です。
- `CTRL_LegIK_L/R` で足の位置、`CTRL_LegAngle_L/R` で脚の向き、`CTRL_Toe_L/R` でつま先を調整します。足裏を床に置く場合は、先に足のIKを調整してからつま先を処理します。
- `CTRL_Root`、`CTRL_Center`、`CTRL_Groove`、`CTRL_Pelvis` は全体の位置、重心、骨盤を調整します。ポーズだけを変えるなら胴体の回転を優先し、キャラクター全体を移動させる場合だけRootやCenterを動かします。

## 4. 指・目・表情

- 指のコントロールは `CTRL_Thumb_1_L` や `CTRL_Index_1_R` のような名前です。根元から指先に向かって番号が付きます。同じ手の複数の指をまとめて選んでキーを打つと、手の形を保ちやすくなります。
- `CTRL_Eye_L` と `CTRL_Eye_R` で目線を調整します。あるフレームで目線を作り、後のフレームで方向を変えてキーを打つと、別の場所を見る動きになります。
- 顔のコントロールは `CTRL_Face_` で始まり、目・口・眉などのグループに分かれています。顔スライダーを選び、Sequencerでチャンネル横のキーアイコンをクリックして値を記録します。表情は通常0から1の値で操作します。表情を保持したい場合は、開始と終了の両方で同じ値をキーにします。
- **MMD2Unreal 2.1.05以降、Control Rigの表情スライダーが生成されるのはPMXのVertex Morph（頂点Morph）のみです。Bone、Group、UV、Material、Flip、Impulse Morphは `CTRL_Face_` パネルには表示されません。**
- PMXモデルによって表情の数や日本語名は異なります。表情が見つからないときは、該当する顔グループを展開してください。Rigアセットを直接編集する必要はありません。

## 5. キーとカーブを調整する

1. Control Rigトラックを展開し、コントロールの移動、回転、表情チャンネルを表示します。
2. タイムライン上でキーをドラッグして発生タイミングを変えます。Curve Editorでは補間方法や接線を調整して、動きの始まりと終わりを滑らかにできます。
3. キーの前後でキャラクターが震える場合は、まず隣り合う回転が大きく飛んでいないか確認します。キーを移動するかカーブを直し、1つのポーズを直すためにControl Rigトラック全体を削除しないでください。
4. コントロールのキーはLevel Sequenceに保存されます。`CR_` と `CRMMD_` はコントロールとスケルトンの解決方法を定義するだけです。モーションを残すにはシーケンスを保存すればよく、Rigアセットを保存・変更する必要はありません。

## 6. プレビューと保存

1. 重要なキーの間をスクラブし、Playを押してモーション全体を確認します。
2. 腕や脚の反転、床へのめり込み、手に指が追従しない問題、目や表情が意図したフレームで変化するかを確認します。
3. 髪やスカートなどの物理エフェクトは、シーン再生時にリアルタイムで計算されます。物理の動きを手作業でキーにする必要はありません。
4. Level Sequenceを保存します。完成したモーションをMMDへ持ち帰る場合は、[09 キャラクターモーション VMD の書き出し](09-キャラクターモーションの書き出し.md)へ進んでください。書き出し時にはSequencer上のキャラクターの最終モーションと表情が読み取られます。

## よくある問題

### `CR_` または `CRMMD_` を選べない

キャラクターが本プラグインでインポートしたSkeletal Meshを使っていること、モデルのインポート時に **Rigバインディングを作成** がオンだったことを確認します。Control Rigアセットの読み込みが終わっているかも確認してください。モデルをインポートした直後なら、コンテンツブラウザの更新を待ってLevel Sequenceを開き直します。

### Rigを追加するとキャラクターが変なポーズになる

別モデルのRigを選んだか、別のキャラクターバインディングに追加した可能性があります。Control Rigセクションを削除し、このキャラクターのSkeletal Meshトラックの下に対応する `CR_` / `CRMMD_` を追加し直してください。

### キーはあるのに再生時に変化しない

コンテンツブラウザから開いたRigアセットではなく、Sequencerに追加したControl Rigのコントロールを編集しているか確認します。コントロールが表示されていること、再生ヘッドがControl Rigセクションの範囲内にあることも確認してください。

### このモーションをどう書き出すか

コントロールを手作業でボーンアニメーションへ変換する必要はありません。Level Sequenceを保存し、[キャラクターモーション VMD の書き出し](09-キャラクターモーションの書き出し.md)で現在のSequencerをソースに選びます。
