# 10 カメラの書き出し

ここまでの章は「MMDからUnrealへ持ち込む」話でしたが、この章は逆方向です。Unrealで調整したカメラワークを `.vmd` ファイルとして保存し、MMDに持ち帰ったり、まだMMDを使っている友達に共有したりできます。

> **お知らせ**：本マニュアルは中国語の原文（正式版）をもとにAIで翻訳したものです。表現が完全に正確ではない場合があります。

## この機能の役割

Unrealではカメラを自由に調整できます。位置を動かし、テンポを変え、新しい動きを加えられる。納得したらワンクリックで、ショット全体の最終結果をMMDが直接開ける `.vmd` カメラファイルにまとめます。つまり：**Unrealで見えたままが、そのままMMDで再現されます。**

## 書き出し手順

![カメラ書き出し](../DocPic/Camera_Out1.jpg)

1. コンテンツブラウザで、以前インポートした（またはUnrealで作った）カメラシークエンスを**ダブルクリック**します。タイムライン付きの編集ウィンドウが開きます。
2. ウィンドウ上部のツールバーから **M2U** と書かれたボタン（小さなカメラアイコン）を探します。見つからない場合はアイコンにマウスを乗せると説明が出ます。
3. ボタンを押すと書き出し設定ウィンドウが出ます。
4. 以下の説明に従って設定します。
5. **VMD を書き出す** を押し、保存場所とファイル名（初期値は `シークエンス名_Camera.vmd`）を決めます。
6. 完了すると結果レポートが表示されます。

## 各オプションの意味

![カメラ書き出し設定](../DocPic/Camera_Out2.jpg)

まず背景から：MMDはカメラを「どの基準点を中心に、そこからどれくらい離れ、どんな角度を向くか」で記録します。一方Unrealのカメラは自由です。そのため、書き出しで最も重要なのは、**この基準点がどこか**をプラグインに教えることです。

### カメラ原点 Binding（基準点は誰か）

ドロップダウンには、このカメラシークエンスに登場するものが並びます：

- **キャラクターを選ぶ**（最も一般的）：キャラクターを基準に書き出されるため、MMDで開いたときのカメラとキャラの位置関係が元どおりになります。
- **未選択（座標を手動入力）**：何も選ばず、下のX・Y・Z欄に自分で基準点の座標を入力します。

### 原点ソース / Component・Bone・Socket

基準オブジェクトを選んだ後、その体のどの部分を基準にするかを指定します：

- **アクタ トランスフォーム（Actor Transform）**：物体全体の位置を使います。最も簡単で、たいてい十分です。
- **コンポーネント / ボーン・ソケット トランスフォーム**：モデルの特定の骨に基準点を追従させます。下の名前欄は `全ての親`（モデルの根っこの骨）が初期値で、通常は変える必要がありません。

### 原点評価

- **書き出し開始時に固定（Lock at Export Start）**：基準点の位置を1フレーム目の時点で固定します。初期値であり、ほとんどの場合これでOK。
- **毎フレーム追従（Follow Every Frame）**：基準点の位置を毎フレーム読み直します。参照オブジェクト自体がシーン内を移動する場合に便利です。

MMDで確認したときにカメラと画面がずれている場合は、もう片方の選択肢で書き出し直してみてください。

### フレーム範囲

- **現在の範囲**：タイムライン全体を書き出します。
- **カスタム範囲**：開始フレームと終了フレームを指定して一部だけ書き出します。作品の前半だけ欲しいときなどに使います。

### 詳細設定（初期状態では折りたたまれており、触らなくてOK）

精度に関する4つの数値です。許容差が小さいほどキーが多く高精度、大きいほどファイルが軽くなります。「汎用カメラ距離」はMMDの標準的な距離の値で、初期値のままで大丈夫です。分からなければ何もいじらないでください。

## 結果レポートの読み方

書き出しが成功すると、次のような数字が表示されます：

| 数字 | 意味 |
|---|---|
| 密サンプル数 | 照合したフレーム数 |
| ショット数 | 認識されたカメラ切り替えの回数 |
| 疎なVMDキー数 | 最終的にファイルに書き込まれたキー数 |
| 最大位置・回転・画角誤差 | 元の画面との最大のずれ |

3つの誤差がごく小さければ成功です。警告が表示されても、それは細部で取捨選択があったことを示すだけで、通常は問題ありません。

## よくある問題

### カメラを書き出すときにM2Uメニューが見つからない

Sequencerで書き出したいLevel Sequenceを開き、タイムラインに **Camera Cut** があることを確認してください。キャラクターモーションを書き出したい場合は、[09 キャラクターモーション VMD の書き出し](09-キャラクターモーションの書き出し.md)を参照してください。
