# 09 キャラクターモーション VMD の書き出し

前の章までは、MMDのコンテンツをUnrealへ持ち込む手順でした。この章では逆に、Unrealで調整したキャラクターモーションを、MMDで直接開けるキャラクターモーション `.vmd` ファイルとして保存します。ボディモーションと表情を一緒に持ち帰ることができます。

> **お知らせ**：本マニュアルは中国語の原文（正式版）をもとにAIで翻訳したものです。表現が完全に正確ではない場合があります。

## 始める前に

- このプラグインで対応する `.pmx` モデルをインポート済みであること。
- Sequencerの演技を書き出す場合は、キャラクターをLevel Sequenceに配置し、そのシーケンスをSequencerで開いていること。
- 単独のAnimation Sequenceを書き出す場合は、対応するMMD Skeletal Meshを先に **Preview Mesh** に設定すること。アニメーションと同じMMDモデルのメッシュを指定してください。

## 2つの書き出し方法

### Sequencerからキャラクターモーションを書き出す

![Sequencerからモーションを書き出す](../DocPic/Motion_Out1.jpg)

1. コンテンツブラウザで書き出したいLevel Sequenceを**ダブルクリック**し、Sequencerで開きます。
2. タイムラインに書き出したいキャラクターがあることを確認します。
3. Sequencer上部のツールバーにある **M2U** ボタンを押し、メニューから **キャラクターモーション...** を選びます。
4. この章の後半の説明に従って設定します。
![モーション書き出し設定](../DocPic/Motion_Out2.jpg)
5. **VMD を書き出す** を押し、保存場所とファイル名を決めます。初期ファイル名はキャラクター名に `.vmd` を付けたものです。
6. 進行状況が終わるまで待ちます。完了すると結果レポートが表示されます。

### Animation Sequenceからキャラクターモーションを書き出す

![Animation Sequenceからモーションを書き出す](../DocPic/Motion_Out3.jpg)

1. コンテンツブラウザで**1つ**のAnimation Sequenceを選択します。
2. 右クリックして **モーション VMD を書き出す...** を選びます。
3. 表示されたウィンドウでPreview Meshが対応するMMDモデルになっていることを確認し、この章の後半の設定を行います。
![Animation書き出し設定](../DocPic/Motion_Out4.jpg)
4. **VMD を書き出す** を押し、保存場所とファイル名を決めます。初期ファイル名はAnimation Sequence名に `.vmd` を付けたものです。
5. サンプリングが終わるまで待ち、結果レポートを確認します。

右クリックメニューに **モーション VMD を書き出す...** がない場合は、フォルダやモデル、複数のアニメーションではなく、1つのAnimation Sequenceを選択しているか確認してください。対応する **Preview Mesh** の設定も必要です。

## 各オプションの意味

### キャラクター / アニメーション

- Sequencerから書き出す場合、**キャラクター** のドロップダウンにはシーケンス内のSkeletal Mesh Bindingが表示されます。実際に書き出したいキャラクターを選びます。
- Animation Sequenceから書き出す場合は、選択中のアニメーションが表示されるため、キャラクターを追加で選ぶ必要はありません。

### 基準アクタ（Sequencerからの場合のみ）

キャラクターはシーン内の任意の位置に配置されていることがあります。基準設定では、書き出し時にキャラクター全体の位置をどのオブジェクトを基準にするか指定します。通常は「キャラクター」と同じActorを選べば大丈夫です。

#### 基準ソース

- **アクタ トランスフォーム**：Actor全体の位置と回転を使います。最も簡単で、初回の書き出しにおすすめです。
- **コンポーネント トランスフォーム**：Actor上の指定したコンポーネントの位置と回転を使います。
- **ボーン / ソケット トランスフォーム**：キャラクターの指定したボーンまたはSocketを使います。名前欄の初期値は `全ての親`（モデルのルートボーン）です。

#### 基準評価

- **書き出し開始時に固定**：書き出し開始時の基準位置を基準にします。シーン内にキャラクターを配置しただけで、後からタイムライン上で動かす場合に向いています。後半の移動も記録できます。
- **毎フレーム追従**：毎フレーム基準オブジェクトを基準にし直します。キャラクターActor自体が動き、相対的な演技だけを書き出したい場合に便利です。

迷ったときは、同じキャラクター、**Actorトランスフォーム**、**書き出し開始時に固定** を選んでください。

### フレーム範囲（Sequencerからの場合のみ）

- **現在の Sequencer 範囲**：タイムラインの再生範囲を書き出します。
- **カスタム範囲**：開始フレームと終了フレームを入力し、その部分だけを書き出します。指定するフレームは現在の再生範囲内でなければなりません。

Animation Sequenceから書き出す場合はアニメーション全体の長さを使うため、別途フレーム範囲を指定する必要はありません。

### キー生成アルゴリズム

VMDにいくつキーを残すか、書き出しにどれくらい時間がかかるかを決める項目です。

- **カーブフィットソルバー**：比較的少ないキーでモーションを再現します。精度を重視し、MMDで使い続けたい場合に向いています。計算に時間がかかり、Sequencerからの書き出しでは初期値です。
- **高速線形補間**：高速に書き出せ、キー数も適度です。まず結果を確認したいときに便利ですが、MMDで後から細かく調整する場合はカーブフィットより自然でないことがあります。Animation Sequenceからの書き出しでは初期値です。
- **完全フレームベーク**：すべてのフレームにデータを書き込みます。ファイルが大きくなり、データ量が多すぎてMMDで読み込めない可能性があるため、通常はおすすめしません。

#### 高度なカーブフィット（「カーブフィットソルバー」のみ）

**カーブフィットソルバー** を選ぶと、初期状態では閉じている **高度なカーブフィット** を開けます。この4項目は、キー数を減らすことと元のモーションをできるだけ再現することのバランスを決めます。通常は初期値のまま使うのが最も安全です。**高速線形補間** または **完全フレームベーク** ではこの項目は表示されず、設定も書き出しに使用されません。

| 項目 | 初期値（設定範囲） | 役割と調整の目安 |
|---|---:|---|
| **位置許容差（cm）** | 0.10（0.01–10） | 保持するキー間で許容する位置フィット誤差です。小さくすると移動の細部をより忠実に残せますが、キー数・ファイルサイズ・書き出し時間が増えます。大きくするとキーを減らしやすくなります。単位はUnrealのcmで、プラグインがモデルのインポート倍率に合わせて内部処理します。 |
| **回転許容差（度）** | 0.20（0.01–10） | 許容するボーン回転のフィット誤差です。指や頭など細かな回転が重要な部分では小さくし、通常の体のモーションを圧縮したい場合だけ慎重に大きくしてください。 |
| **モーフフィット許容差** | 0.01（0.0001–0.25） | モーフの重みを線形フィットするときの許容誤差です。小さいほど口形・まばたき・表情変化を多く残し、大きいほど近いモーフキーをまとめます。 |
| **モーフゼロしきい値** | 0.005（0–0.10） | 絶対値がこの値以下のモーフ重みを0として扱い、微小な浮動小数点ノイズを取り除きます。大きくすると不要なモーフデータを減らせますが、弱い表情まで失われることがあります。 |

まず初期値で書き出し、MMDで結果を確認してください。細部が簡略化された場合は、関係する許容差だけを下げます。ファイルが大きすぎる、または書き出しが遅い場合は、位置・回転・モーフフィットの許容差を少しずつ上げます。すべての値を一度に大きくすると、品質低下の原因を判断しにくくなります。

### 書き出し対象のボーングループ

モデルのPMXファイルにあるボーングループと、ユーザーが作成したグループが表示されます。VMDに書き込みたいグループにチェックを入れてください。少なくとも1つのグループを選択する必要があります。未分類ボーンは初期状態では除外されます。

初期設定では、髪、スカート、物理に見える名前のグループを避けます。これらは通常、再生時に物理システムが計算する部分だからです。

- **物理ボーンを含める**：初期状態はオフです。オフの場合、グループを選択していても動的なPMX物理ボーンは除外されます。物理の動きをファイルに焼き込みたい場合だけオンにしてください。
- **モーフモーションを含める**：初期状態はオンです。まばたきや口形など、モデルに存在する表情を含めます。オフにするとボーンモーションだけを書き出します。

ウィンドウ下部の **Model Data** が利用可能になっている必要があります。これはモデルのインポート時に作成された情報で、ボーンと表情を正しいMMD名で書き出すために使われます。

### 作業量の見積もり

ウィンドウには、計算対象のボーン数・フレーム数と、おおよその所要時間が表示されます。あくまで目安であり、モデルの複雑さやPCの速度で実際の時間は変わります。カーブフィットや完全フレームベークは、通常より時間がかかります。

キャラクターモーションの書き出しはMMDで一般的な30 FPSの時間基準を使うため、書き出しフレームレートを別に選ぶ必要はありません。

## 結果レポートの読み方

書き出しに成功すると、指定した場所にVMDファイルが保存されます。レポートの数字は次の意味です。

| 数字 | 意味 |
|---|---|
| 密サンプル数 | プラグインが実際に確認したモーションのフレーム数 |
| 候補ボーン | 選択したグループから見つかったボーン数 |
| 除外した物理ボーン | 初期フィルターで除外された動的物理ボーン数 |
| 出力ボーントラック | VMDに最終的に書き込まれたボーン数 |
| ボーンキー | 出力ファイルのキャラクターモーションキー数 |
| モーフキー | 出力ファイルの表情キー数 |

警告が表示されても、ファイル自体は正常に書き出されている場合があります。よくある例は、メッシュに存在しないボーン、VMDの名前制限に合わない表情名、VMDに保存できないボーンスケールです。該当部分はスキップされ、詳細はOutput Logで確認できます。

## よくある問題

### キャラクターモーションを書き出すときにM2Uメニューが見つからない

- Sequencerから書き出す前に、SequencerでLevel Sequenceを開き、シーケンス内にSkeletal Meshキャラクターがあることを確認してください。
- 単独のアニメーションを書き出す場合は、コンテンツブラウザで1つだけAnimation Sequenceを選択し、右クリックして **モーション VMD を書き出す...** を探してください。

### 書き出しでModel Dataが利用できない、またはPreview Meshが一致しない

キャラクターモーションの書き出しには、モデルのインポート時に作成されたModel Dataが必要です。Animation Sequenceの **Preview Mesh** に同じMMDモデルのSkeletal Meshが設定されているか確認してください。Model Dataが失われた、または利用できない場合は、元の `.pmx` ファイルを戻してモデルを再インポートしてから、もう一度書き出してください。

### 書き出したモーションに表情がない

キャラクターモーションの書き出しウィンドウで**モーフモーションを含める**をオンにしてください。それでもレポートのモーフキーが0の場合は、モデルのインポート時に**表情の取り込み**を有効にしたか、元のモーションに表情カーブがあるか確認します。

### 書き出したあと髪やスカートが動かない

キャラクターモーションの書き出しでは、動的な物理ボーンは初期状態で除外されます。MMDへ持ち帰った場合、髪やスカートの動きは通常MMDの物理システムが再計算します。通常のボーンモーションが失われたという意味ではありません。物理ボーンの姿勢をVMDに書き込みたい場合は**物理ボーンを含める**をオンにできますが、ファイルは大きくなります。

### キャラクターモーションの書き出しが遅い、またはVMDが大きすぎる

**キー生成アルゴリズム**では、キーを減らしたいときは**カーブフィットソルバー**、結果を素早く確認したいときは**高速線形補間**を選びます。**完全フレームベーク**はすべてのフレームを書き込むため、必要な場合以外は避けてください。MMDで読み込めないほど大きくなる可能性があります。

### レポートのボーン数が想定より少ない

必要なボーングループにチェックが入っているか確認してください。未分類ボーンは初期状態で除外され、**物理ボーンを含める**がオフの場合は動的な物理ボーンも除外されます。レポートの「除外した物理ボーン」の数が判断材料になります。

### キャラクターモーションVMDには何が書き出されるか

キャラクターのボーンモーションと、モデルに存在する表情が書き出されます。カメラについては[10 カメラの書き出し](10-カメラの書き出し.md)を参照してください。マテリアルやステージなど、その他のMMDコンテンツは現在MMDへ書き出せません。

## MMDへ持ち帰るときの注意

- 書き出しに使ったものと同じモデルでVMDを開いてください。日本語のボーン名と表情名が正しく対応します。
- 動的な物理ボーンは初期状態ではファイルに含まれないため、髪やスカートの動きは通常、MMD再生時に物理システムが再計算します。通常のボーンモーションには影響しません。
- この機能が書き出すのはキャラクターモーションと表情で、カメラデータは含みません。カメラについては [10 カメラの書き出し](10-カメラの書き出し.md) を見てください。
