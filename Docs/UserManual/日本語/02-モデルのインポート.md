# 02 モデルのインポート

この章では、MMDの `.pmx` モデルをUnrealに持ち込む方法を説明します。インポートが終わると、シーンにドラッグでき、表情も作れ、髪やスカートが自然に揺れるキャラクターが手に入ります。

> **お知らせ**：本マニュアルは中国語の原文（正式版）をもとにAIで翻訳したものです。表現が完全に正確ではない場合があります。

## 始める前：モデルフォルダを確認する

`.pmx` ファイルは単独では動きません。色や服の模様は、その横にあるテクスチャファイルに入っています。次のことを確認してください：

- モデルと専用テクスチャが元のフォルダで一緒になっていること。
- `.pmx` ファイルだけを受け取った場合は、まず配布者に完全なパッケージを求めてください。

## インポート手順

1. Unreal下部の**コンテンツブラウザ**（アセットのサムネイルが並ぶ領域）を探します。最初にこのモデル用の空フォルダを作っておくのがおすすめです。
2. `.pmx` ファイルをコンテンツブラウザに直接ドラッグします。
3. インポート設定ウィンドウが出ます。初回は何も変えず、右下の**インポート**ボタンを押すだけでOKです。
4. 進行状況が終わるのを待ちます。大きなモデルほど時間がかかりますが、正常な現象です。
5. 完了すると、フォルダにはモデル関連の一式が揃っています。
6. 忘れずにこまめに保存してください。手動で保存しないままUnreal Editorを閉じると、インポートしたアセットは消えてしまいます。

## 各オプションの意味

ウィンドウの選択肢をグループごとに説明します：
![インポートウィンドウ](../DocPic/PMX_import.jpg)

### アセットタイプ

- **キャラクター（Character）**：人物モデル。ほとんどの場合はこれを選びます。
- **シーン（Scene）**：ステージ・部屋・家具など、自分では動かないモデル。

### テクスチャと見た目

- **テクスチャをインポート（Import Textures）**：モデルが使う色や模様のファイルも一緒に取り込みます。必ずオンのまま。外すと模型が灰色になります。
- **マテリアルを作成（Create Materials）**：Unreal Engineの使用規則に沿った親子マテリアルアセットをモデル用に自動生成します。

### 表情

- **Import Expressions（表情を取り込む）**：瞬き・笑顔・口の開閉などの表情変化が入り、複数の小さな表情を組み合わせた合成表情にも対応します。
- フル体験ならオンのまま。今は体さえあればいいならオフにすると速くなります。

<small>**名称互換のヒント：** 一部の表情名に少し奇妙な `UE5EA_patch_` というプレフィックスが付いているのを見かけることがあります。これは既存の名称互換プレフィックスです。`∧`、`▲`、`□` のような特殊文字の表情名は Control Rig 上でアンダースコアに変換されるため、衝突を避けてこのプレフィックスが付けられます。プレフィックス付きの表情も元の PMX 表情に対応しており、名称マッピング自体は変更されていません。</small>

### ポーズ補助ツール

- **IKアセットを作成（Create IK Asset）**：`IKR_<MeshName>` を生成し、プラグイン内蔵の最小構成のUE5 Mannyアセットを使って、Manny → MMD用の `RTG_<MeshName>` とMMD → Manny用の `RTG_<MeshName>_ToManny` も生成します。2つのRTGには基本的な口形とまばたきの対応も自動で入り、一般的なMMD表情とARKit系の表情カーブを一緒に変換できます。
- **Rigバインディングを作成（Create Rig Binding）**：Sequencerでポーズ調整やモーション作成に使う `CR_` / `CRMMD_` Control Rigを生成します。
- **腕の拘束補正（Arm Constraint Correction）**：上腕・前腕・手が胴体、首、頭部、脚、反対側の腕へ入り込むのを抑えます。キャラクターのインポートでは初期状態で有効、シーンのインポートでは初期状態で無効です。ここでは初期値のままで構いません。モーション導入後に [05-2 腕の拘束補正](05-2-腕の拘束補正.md) で Debug Draw と詳しい調整方法を説明します。
- よく分からなくても**初期値（オン）のままで大丈夫**です。通常のインポートを妨げるものではありません。

### 物理

- **フィジックスを有効化（Enable Physics）**：髪・スカート・アクセサリーがモーションに合わせて自然に揺れます。デフォルトでオンです。
- **ワールド物理コリジョン（World Physics Collision）**：揺れる部分がシーン内の壁や床に押し返されるかどうか。例えばキャラが壁際に立つとき、髪が壁にめり込まず押しのけられます。**キャラクターではデフォルトでオン、シーンではデフォルトでオフです。**
- スカートのように複数のボーンチェーンから成る構造では、PMXにあるチェーン間Jointをできるだけ使い、隣り合うスカートパネルの関係を保ちます。規則的なリング状スカートでは、安全に判断できる場合に不足している横方向の接続も自動補完されます。通常は手作業で接続を作る必要はなく、他のKawaiiPhysicsノードと同じように効果だけを調整できます。

## インポート後に得られるもの

インポート先のフォルダを開くと、次のようなものがあります：

| 見えるもの | 正体 |
|---|---|
| シーンにドラッグできるキャラクター | モデル本体。ダブルクリックで確認できる |
| `Materials` フォルダ | モデルのマテリアル |
| `Textures` フォルダ | モデルのテクスチャ |
| `RM_<MeshName>` ファイル | PMXモデルのコメントを保存するテキストアセット。ダブルクリックで確認できる |
| `IKR_` で始まるファイル | 現在のPMXモデルのIK Rig。リターゲット用チェーン、IK Solver、Goalを記録する |
| `RTG_<MeshName>` / `RTG_<MeshName>_ToManny` | それぞれManny → MMD、MMD → Mannyのモーション変換に使うIK Retargeter。基本的な口形とまばたきのカーブも一緒に変換する |
| `CR_` か `CRMMD_` で始まるファイル | 現代的な手動ポーズ用Rigコントローラー |
| `ABP_Post_` で始まるファイル | MMDのIK・追加変形・腕の拘束補正（体と脚の回避を含む）・物理をリアルタイムに適用するAnimation Blueprint。物理を有効にした場合は第03章に従って調整できます |

マテリアルとテクスチャはそれぞれ `Materials` と `Textures` サブフォルダに整理されています。

SDEFを含むモデルでは、この `ABP_Post_` にネイティブSDEF姿勢補正ノードも自動で含まれます。通常は手動で追加・削除・移動しないでください。

`RM_<MeshName>` はPMXモデルのコメントから生成されるテキストアセットで、追加のモデルファイルではありません。PMXに日文・英文コメントがある場合はそれらを保持します。ダブルクリックで内容を確認でき、モデルを再インポートするとテキストも更新されます。

開発中にはPMXD Mesh Deformer方式が存在しましたが、リアルタイムプレビューの性能と多数の互換性問題を考慮し、現在は一時的に削除しています。現在のインポートではPMXDファイルは生成されず、モデルの `RM_` 説明にもスキニングの制限が記載されます。

現在の配布パッケージには双方向リターゲットに必要な最小構成のMannyアセットが同梱されています。そのため、通常は **IKアセットを作成** を有効にしてインポートするだけで `IKR_<MeshName>` と2方向のRTGが生成され、プロジェクト側でMannyアセットを用意する必要はありません。プラグイン内蔵アセットが欠損または破損している場合は、インポート警告に理由が表示されます。逆方向変換では `_ToManny` アセットを使用し、正方向RTGのプレビュー模型だけを入れ替えないでください。既存モデルでは再インポート時にIKアセットの上書きだけを選ぶことで、両方向を再生成できます。

### 双方向 RTG の例

![MMD から Manny への RTG](../DocPic/RTG_MMDout.jpg)

`RTG_<MeshName>_ToManny` は MMD → Manny 用で、専用の Operation Stack を持ちます。

![Manny から MMD への RTG](../DocPic/RTG_toMMD.jpg)

`RTG_<MeshName>` は Manny → MMD 用で、MMD 用の身体・IK 処理を設定します。

### 2つのRTGで一緒に変換される基本表情

現在は、よく使うMMDの5つの母音口形と通常のまばたきを自動で扱います：

| MMD表情 | 対応するARKit系表情 |
|---|---|
| `あ` | 口を開く `jawOpen` |
| `い` | 口を横に引く `mouthStretch` |
| `う` | 唇をすぼめる `mouthPucker` |
| `え` | 口角を締める `mouthDimple` |
| `お` | 丸い口形 `mouthFunnel` |
| `まばたき` | まばたき `eyeBlink` |

`RTG_<MeshName>` はManny / ARKit系のこれらの表情をMMDモデルへ渡します。`RTG_<MeshName>_ToManny` はMMDの表情をManny / ARKit系カーブへ戻します。左右がある表情（左右のまばたきなど）は、必要に応じて両側へ自動で割り当てられます。

これは**異なる表情体系を使いやすくつなぐためのおおまかな見た目の対応**であり、音声の音素を正確に変換する機能ではありません。キャラクターごとに口形デザインは大きく異なるため、見た目が合わない口形はターゲット側の表情カーブを追加調整してください。

この機能が追加される前にインポートしたモデルでは、PMXを再インポートし、**IK Rig / IK Retargeter** の上書き項目だけを選ぶことで2つのRTGを再生成できます。この機能だけのためにモデル本体を上書きする必要はありません。

## 既存の PMX を再インポートする

同名の `.pmx` を元の Unreal フォルダへもう一度ドラッグしても、M2U はすぐに上書きせず、先にリスク警告を表示します。

旧バージョンを残したい場合は、これまでどおり**モデル名を変更して新しいフォルダへインポートする**方法が最も安全です。新しい PMX で既存モデルを更新したいことを確認できている場合は、警告ウィンドウの **PMXモデルを再インポート** を選択します。その後、2つ目の **PMX 再インポートオプション** ウィンドウで、今回どの既存アセットを上書きするか選べます。

**Skeletal Mesh を上書きして Skeleton を同期** は一つのコア項目で、片方だけを更新することはできません。Skeletal Mesh を上書きしながら、互換性のある骨格データを既存の Skeleton へ同期します。既存 Skeleton アセット自体とアセットパスは維持されます。追加ボーンやリファレンスポーズの変更はその場で同期できますが、既存ボーンの削除、名前変更、親変更は書き込み前に拒否されます。この項目は既定でオンなので、そのまま確定すればモデル本体、スケルトン、表情と関連するコアデータは通常どおり更新されます。マテリアルとテクスチャは独立して上書きを選択できます。

PhysicsAsset、Post Process AnimBP、IK Rig / IK Retargeter、Control Rigもそれぞれ独立して上書きを選択できます。コア項目をオフにしても、これらの付随項目が強制的に無効になることはありません。チェックした付随アセットは現在実際に使われているモデルとSkeletonを基に更新され、チェックしていない既存アセットはプラグイン側から再生成、名前変更、コンパイル、保存、削除されません。そのため、モデル本体を上書きせずに2方向のRTGやControl Rigなどだけを再構築できます。

古いモデルにSDEFが含まれ、まだ現在のネイティブSDEF表現へ移行していない場合、初回の移行では **Skeletal Mesh を上書きして Skeleton を同期** と **既存の Post Process AnimBP を上書き** の両方を選択してください。片方だけでは移行を完了できません。コア項目だけの更新は拒否され、古いSDEF変形経路へ自動的に戻ることもありません。

注意点：

- 再インポートは上書き操作で、ワンクリックでは元に戻せません。重要なモデルは先にバックアップしてください。
- 自動生成された Rig、マテリアル、その他の関連アセットに手動で加えた変更は、その項目を今回上書き対象にした場合、再構築または上書きされることがあります。
- 新しい PMX から削除されたマテリアル、テクスチャ、その他の付随アセットは、現時点では Unreal 側から自動削除されません。不要であることを確認してから手動で整理してください。

## よくある問題

### モデルをドラッグしても何も起きない

順に確認してください：

1. **Edit > Plugins** でプラグインとKawaiiPhysicsの両方が有効になっているか。インストール後はエディタの再起動も必要です。
2. 圧縮ファイルではなく `.pmx` ファイル本体をドラッグしたか。
3. コンテンツブラウザの別のフォルダでもう一度試す。

1つ目が通らない場合は、[ダウンロードとインストール](01-ダウンロードとインストール.md)を見直してください。

### インポートできたのにモデルが灰色・白色のまま

テクスチャが一緒に入っていません。最も多い原因は、テクスチャが `.pmx` と別の場所にあることです。完全な素材フォルダを元どおりに揃え、灰色のモデルを削除して再インポートし、**Import Textures（テクスチャをインポート）** にチェックがあるか確認してください。

### MMDと見た目がわずかに違う

SDEFを含むモデルはUEネイティブスキニングと自動生成の姿勢補正を使用します。QDEFは現在、4ボーンのウェイトを使うBDEF4リニアスキニングへ変換されます。双対クォータニオン変形は再現されず、ねじりや曲げでMMDより収縮・扁平化する場合があります。SDEFとQDEFの混在モデルもインポートできます。SDEF姿勢補正はインポート時のLOD0のみを対象とし、後から生成した簡略化LODには対応する補正データがありません。姿勢補正を完全に生成できない場合はインポートに失敗します。特殊なボーンや独自の制約でもMMDとの差が生じる場合があります。

### MMD特有の光沢や輪郭が完全には再現されない

MMDのSphere、Toon、Edgeなどのマテリアル表現は現在、基本マテリアルを中心に処理されます。そのため、一部の光沢や輪郭の見え方がMMDと異なる場合があります。

### 同名競合が表示される

フォルダに同名アセットがあります。M2U はそのまま上書きせず、まずリスク警告を表示します。

- 現在のバージョンを残す：インポートを中止し、モデル名を変更するか新しいフォルダを使います。
- 既存モデルを更新する：残したい変更をバックアップしたことを確認してから **PMXモデルを再インポート** を押し、2つ目のウィンドウで今回上書きしてよいアセットを選択します。
