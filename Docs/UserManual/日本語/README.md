# MMD2Unreal ユーザーマニュアル

このマニュアルは、MMDコミュニティのエコシステムを続けながら、より現代的なソフトウェアツールも使いたい方のためのものです。

プログラミング知識は不要です。MMDを理解し、UEエンジンに触れてみようという気持ちがあれば十分です。

とても簡単です！ 手順に沿ってクリックするだけで完成します。

> **注**：このディレクトリでは中国語版をマニュアルの母本とし、Englishと日本語は対応する翻訳版です。

## 対応環境

- Unreal Engine 5.8（可能であればEpic Games Launcherからダウンロード・インストールしてください）
- Windows 64-bit（x86-64 / Win64）PC

現在の配布パッケージは、Windows ARM、macOS、Huawei HarmonyOS PC、およびUnreal Engine 5.8 Win64 Editorを実行できないその他のデバイスには対応していません。

## 1分でわかる全体の流れ

1. **インストール**：リリースページからダウンロードし、プロジェクトのPluginsフォルダに入れ、プロジェクトを開いたときに有効化する。
2. **モデルをドラッグ**：`.pmx` ファイルをUnreal下部のコンテンツブラウザにドラッグし、インポートを押すだけ。キャラクターモデルとステージモデルに対応しています。
3. （おまけ）**姿勢と物理を調整**：インポート時に **フィジックスを有効化** をオンにした場合は、姿勢を確認し、`ABP_Post_` のKawaiiPhysicsでコリジョンを選んで物理を調整します。
4. （おまけ）**マテリアルを調整**：モデルの見た目を変えたい場合は、対応するマテリアルインスタンスを開き、公開済みの属性を調整します。
5. **モーションをドラッグ**：ダンス用の `.vmd` ファイルもドラッグし、先ほどインポートしたMMDモデルを選びます。
6. （おまけ）**腕の拘束補正を確認**：キャラクターのインポートでは初期状態で有効になり、腕や手が体、脚、反対側の腕を貫通するのを抑えます。モーション導入後の確認・調整は05-2章を参照してください。
7. **カメラをドラッグ**：カメラ用の `.vmd` ファイルをドラッグすれば、Unreal内で再生できるカメラシークエンスが手に入ります。
8. （おまけ）**Rigでモーションを作る**：Sequencerで `CR_` / `CRMMD_` Control Rigを使ってゼロから作るか、`CRMMD_` を既存モーションの上に分層して修正します。
9. （おまけ）**持ち帰る**：Unrealで調整したキャラクターモーションやカメラを `.vmd` ファイルとして書き出し、MMDに持ち帰れます。

インポート全体はファイルをフォルダにドラッグするのと同じくらい簡単です。**ドラッグ＆ドロップができれば、このプラグインは使えます。**

インポート後の手順もUEのネイティブな体験に限りなく近く、**別の単独ウィンドウを開く必要はありません。**

## 使い始める前の心構え

- このマニュアルの手順は、ファイルをドラッグ、項目にチェック、ボタンを押す、この3つだけです。
- インポート後、プロジェクトには名前の不思議な小さなファイル（`IKR_`、`RTG_`、`ABP_Post_`、`RM_` などで始まるもの）がいくつか現れます。これらはプラグインが自動で用意したアセットです。`RTG_` はManny → MMDとMMD → Mannyの2方向リターゲットに使い、`RM_` にはPMXモデルのコメントが保存されます。従来の手順の99%を解決済みで、調整が必要な場合もとても簡単です。
- 選択肢の意味が分からないときは、初期値のままにしておくのが常に最も安全です。
