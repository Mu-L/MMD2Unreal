# 04 M2Uマテリアル調整

この章では、MMDモデルをインポートした後にM2Uマテリアルを理解し、調整する方法を説明します。

## まず理解する：M2Uマテリアルの位置付け

プラグインのM2Uプリセットマテリアルは、マテリアル関数 `MF_MMD_RedialC` を基にした、MMDユーザー向けの基本的な移行用マテリアルです。色、テクスチャ、ラフネス、法線、発光、MMDの `SPA/SPH` スフィアマップといったよく使う調整項目を備えており、Unreal Engineにまだ慣れていないユーザーでも、Ray-MMDに近い考え方でモデルを移行し、見た目を調整できます。

このプリセットは信頼できる出発点です。Ray-MMDを完全に再現するものでも、Unrealのマテリアル機能の上限でもありません。閉じたブラックボックスや、Unrealマテリアルの唯一の使い方だと考えないでください。自分の好みや作業習慣ができたら、Unrealのマテリアルシステムをさらに学び、自分用の親マテリアルを作成できます。

## 初めて調整するときのおすすめの順番

最初からすべてのマテリアルアセット名を理解する必要はありません。まず最終的な `Mi_<モデル名>_<マテリアル名>` マテリアルインスタンスを開きます。Detailsパネルでは、パラメータ左側の上書きチェックを有効にして初めて、その変更がこのマテリアルインスタンスに保存されます。次の順で調整してください。

1. `Diffuse` のベースカラーテクスチャが正しいか確認します。通常はインポート時に自動で割り当てられます。
2. `DiffuseColor` で全体の色味を補正します。服、髪、肌の色を変えたい場合などに使います。
3. `Roughness` で表面をより滑らかに見せるか、よりマットに見せるかを調整します。
4. モデルがMMDのSPA/SPHを使っている場合は、`Sphere` と対応する加算・乗算の強さを確認します。通常のPMXインポートでは自動で設定されます。
5. 最後に `Normal`、`Emissive`、`RimLight`、透明度関連の項目を試します。
6. **Save** を押し、モデルプレビューまたはレベル内で結果を確認します。

`Mi_` に必要な項目がない場合は、まずParentを確認し、親マテリアルがそのパラメータを公開しているか確認してください。調整のたびに保存し、プレビューで確認します。1つのマテリアルスロットを変えるためだけに共有の `MF_MMD_RedialC` を直接編集しないでください。共有関数の変更は、それを使うすべての `MS_` に影響します。

## 現在のプリセットで調整できる属性

以下は、マテリアルインスタンスのDetailsパネルに実際に表示されるパラメータを、パネルと同じグループ順に並べたものです。名前はUIと一致しています。まずは `Diffuse`、`DiffuseColor`、`Roughness` から始めてください。`*Setting` は対応するテクスチャ座標の高度な設定で、明確な目的がない限り初期値のままにします。

### `0.Debug`

| パラメータ | 使う場面 |
|---|---|
| `Z-Fighting` | 重なった面がちらつく、または揺れて見えるときだけ調整します。`0` に近い値から少しずつ試してください。 |

### `1.Diffuse`

| パラメータ | 使う場面 |
|---|---|
| `Diffuse` | ベースカラーテクスチャです。通常はインポート時に自動で割り当てられます。 |
| `DiffuseColor` | 全体の色調整の第一候補です。服、髪、肌の色を変える場合などに使います。白は追加の色付けをしない状態です。 |
| `DiffuseColorProfile` | 全体の色の見え方をさらに調整したいときに使います。通常の色調整では、先に `DiffuseColor` を使ってください。 |
| `DiffuselSetting` | ベースカラーテクスチャの座標に関する高度な設定です。 |

### `2.Roughness`

| パラメータ | 使う場面 |
|---|---|
| `Roughness` | 表面をより滑らかに見せるか、よりマットに見せるかを調整します。基本プリセット値は約 `0.6` です。ラフネスマップを使う前に、まずこちらを調整してください。 |
| `RoughnessMap` | 対応するラフネステクスチャがある場合に使います。 |
| `EnableRoughnessMap` | `RoughnessMap` を有効にするスイッチです。初期状態ではオフです。 |
| `RoughnesslSetting` | ラフネステクスチャの座標に関する高度な設定です。 |
| `Anisotropy` | 異方性の見え方を調整する高度な項目です。通常のMMDマテリアルでは調整不要です。 |

### `3.Specular`

| パラメータ | 使う場面 |
|---|---|
| `Specular` | スペキュラハイライトの強さです。基本プリセット値は約 `0.1` です。迷った場合は初期値のままにしてください。 |
| `Metallic` | 金属度です。布、肌、プラスチックでは通常低い値を使います。 |
| `MetallicMap` | 対応するメタリックテクスチャがある場合に使います。 |
| `EnableMetallicMap` | `MetallicMap` を有効にするスイッチです。初期状態ではオフです。 |
| `MetalSetting` | メタリックテクスチャの座標に関する高度な設定です。 |

### `4.Emissive`

| パラメータ | 使う場面 |
|---|---|
| `Emissive` | 発光テクスチャです。目、アクセサリー、ライト、特殊効果に向いています。 |
| `EmissiveColor` | 発光の色と強さを調整します。通常のベースカラーを発光だけで表現することはおすすめしません。 |
| `RimLight` | リムライトの見え方を調整するスタイライズ用の項目です。 |
| `RimLightSoftness` | リムライトの柔らかさを調整します。基本プリセット値は約 `0.25` です。 |

### `5.Normal`

| パラメータ | 使う場面 |
|---|---|
| `Normal` | 法線マップです。追加の法線マップがない場合は初期値のままにします。 |
| `NormalIntensity` | 法線ディテールの強さを調整します。基本プリセット値は `1.0` です。強すぎる見た目を避けるため、小さく調整してください。 |
| `NormalSetting` | 法線マップの座標に関する高度な設定です。 |

### `6.MMD SPA/SPH`

| パラメータ | 使う場面 |
|---|---|
| `Sphere` | MMDのSPA/SPHスフィアマップです。PMXマテリアルで使われている場合、通常は自動で割り当てられます。 |
| `SphereAddStrength` | SPA（加算）スフィアマップの影響を調整します。PMXインポート時にスフィアマップのモードから自動設定されます。 |
| `SphereMulStrength` | SPH（乗算）スフィアマップの影響を調整します。PMXインポート時にスフィアマップのモードから自動設定されます。 |

### `7.Opacity`

| パラメータ | 使う場面 |
|---|---|
| `Opacity` | 全体の不透明度です。基本プリセット値は `1.0` です。 |
| `OpacityGamma` | 透明度の変化の見え方を調整します。基本プリセット値は `1.0` です。縁が硬すぎる、または柔らかすぎるときだけ試してください。 |
| `EnableShadow` | 透明マテリアルを影に参加させるかを切り替えます。初期状態ではオンです。 |

## 自分の親マテリアルでモデル全体の見た目を素早く置き換える

このマニュアルでいう「マテリアル母体」は、`M_` や `MS_` のようにマテリアルインスタンスが継承できる親マテリアルアセットを指します。自分の調整方法ができたら、親マテリアルを用意し、モデルレベルのマテリアルインスタンスを使ってモデル全体の基本的な見た目を置き換えられます。この方法なら、何十個、何百個もの `Mi_` を1つずつ開く必要がありません。

1. たとえば `M_MyMmdBase` のような自分用の親マテリアルを作成または準備します。既存の `MS_` をコピーして発展させても、自分が慣れた別の構成を使っても構いません。
2. コンテンツブラウザでモデルの `Materials/MotherMat/MSi_<モデル名>` を開きます。
3. Detailsパネルで **Parent** を自分の親マテリアルに変更し、マテリアルインスタンスを保存します。
4. モデルプレビューを確認します。`MSi_<モデル名>` を親に持つすべての `Mi_` は新しい親を通じて更新され、モデル全体の基本的な見た目をまとめて切り替えられます。

PMXからインポートされた `Mi_` のよく使う設定をできるだけ保つには、自作の親マテリアルで少なくとも `Diffuse`、`DiffuseColor`、`Sphere`、`SphereAddStrength`、`SphereMulStrength` のパラメータ名に対応することをおすすめします。新しい親マテリアルに対応するパラメータがない場合、`Mi_` の上書き値はアセットに残りますが、見た目には反映されません。

これはUnrealの親マテリアルとマテリアルインスタンスの継承関係の例です。プラグインの同様の工夫は、インポートを便利にするだけでなく、Unrealのアセット構成、パラメータ継承、一括置換を少しずつ理解できるようにするためでもあります。

### 親マテリアルを置き換えた場合の再インポートに関する注意

同名モデルを再インポートすると、現在のインポーターは `MSi_<モデル名>` の **Parent** をそのモデルの `MS_<モデル名>` に戻します。`MSi_` に独自の親を設定した場合は、再インポート後に確認して再設定してください。この手順を再インポートの作業手順に入れることをおすすめします。

## マテリアルアセットの関係：MS、MSi、Mi（MI）

基本操作を理解してからアセット名を見ると、関係が分かりやすくなります。`MS_` は親マテリアル、`MSi_` と `Mi_` はマテリアルインスタンスです。`MF_` はマテリアル関数であり、マテリアルスロットのParentではなく、親マテリアルとも呼びません。**Create Materials** を有効にしてインポートすると、モデルのマテリアルは通常次の親子関係になります。

```text
Mi_<モデル名>_<マテリアル名>  最終マテリアルインスタンス：1つのPMXマテリアルスロット
└─ MSi_<モデル名>              モデルレベルのマテリアルインスタンス：すべてのMi_で共有
   └─ MS_<モデル名>            モデルレベルの親マテリアル
      └─ MF_MMD_RedialC        共有の基本MMDマテリアル関数
```

- `Mi_<モデル名>_<マテリアル名>`：各PMXマテリアルスロットに対応する最終マテリアルインスタンスです。服、髪など1つのマテリアルだけを調整するときは通常この階層を開きます。
- `MSi_<モデル名>`：`MS_` とすべての最終 `Mi_` の間にある、モデルレベルのマテリアルインスタンスです。**Parent** を置き換えると、モデル全体の親マテリアルを切り替えられます。
- `MS_<モデル名>`：現在のモデルの親マテリアルです。最初のインポート時に `MF_MMD_RedialC` を使って作られます。
- `MF_MMD_RedialC`：複数のモデルで共有できる基本マテリアル関数です。変更前に影響範囲を確認してください。

この文書では、Material Instance（マテリアルインスタンス）の総称として **MI** を使う場合があります。実際のアセット名は `Mi_` と `MSi_` です。大文字・小文字と接頭辞はコンテンツブラウザのファイル名を優先してください。これらのアセットは通常、モデルのインポートフォルダの `Materials` と `Materials/MotherMat` にあります。

## この基本マテリアルから次へ進むとき

複雑なキャラクタースキン、布、ガラス、特殊なライティング、レイヤー化したマテリアル、プロジェクト全体の性能制御が必要になったら、M2Uマテリアルを参考・移行レイヤーとして扱ってください。自分用の `M_` 親マテリアルと `MF_` マテリアル関数を学び、作成できます。`Mi_` の構成を保ったままでも、モデルレベルの `MSi_` 置換点を使って、確立したマテリアルの作業習慣をモデル全体に適用できます。

M2Uの基本マテリアルはUnrealに入るための最初の足場であり、Unrealのマテリアル機能を定義するものではありません。`MS_`、`MSi_`、`Mi_` の役割を理解することは、Unrealで重要なマテリアル継承と一括置換の考え方を使い始めることにつながります。

## 注意事項

- `MS_` または共有の `MF_MMD_RedialC` を変更する前に、影響範囲を確認してください。共有関数の変更は複数の `MS_` に影響する場合があります。
- `MSi_` のParentを置き換える場合は、できるだけパラメータ名に互換性がある親マテリアルを使ってください。そうしないと、`Mi_` に保存されたテクスチャや色の値が新しいマテリアルに反映されないことがあります。
- 同名モデルを再インポートする場合は、`MSi_` が独自の親マテリアルを指しているか、あらためて確認してください。
