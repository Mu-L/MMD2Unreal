# 01 ダウンロードとインストール

この章では、プラグインのダウンロード、プロジェクトへの配置、動作確認の3つを行います。所要時間は5分ほどです。

> **お知らせ**：本マニュアルは中国語の原文（正式版）をもとにAIで翻訳したものです。表現が完全に正確ではない場合があります。

## 用意するもの

- インストール済みの Unreal Engine 5.8
- 作成済みの Unreal プロジェクト（空のプロジェクトで可）
- GitHubにアクセスできるネット環境

## ステップ1：プラグインをダウンロードする

1. プラグインのGitHubプロジェクトページを開きます。
2. ページ右側の **Releases**（リリース版）をクリックします。
3. 版は日付順に並んでいます。一番上の **Latest** の付いたものが最新版です。特定のバージョン番号を気にする必要はなく、これを使えばOKです。
4. 最新版ページ下部の添付ファイル欄（Assets）から、圧縮ファイル（通常は `.zip`）をダウンロードします。
5. ダウンロード後、保存場所を覚えておいてください。

## ステップ2：プラグインをプロジェクトに入れる

1. PC上でUnrealプロジェクトのフォルダを探します。見分け方：プロジェクトと同じ名前の `.uproject` ファイルが入っているフォルダです。
2. フォルダ内に **Plugins** というフォルダがあるか確認します。なければ自分で作成します。名前は一字一句同じにしてください。
3. ステップ1の圧縮ファイルを解凍し、出てきたプラグインフォルダごとPluginsの中に入れます。
4. 配置を確認：プラグインフォルダの中に `MMD2Unreal.uplugin` というファイルが直接あるはずです。つまりパスは `あなたのプロジェクト/Plugins/MMD2Unreal/MMD2Unreal.uplugin` の形になります。開いたらまた同名フォルダが出てくる場合は、中のフォルダを一段上に移動してください。

## ステップ3：物理エフェクト用コンポーネントを入れる（必須）

インポート後の髪やスカートの揺れには、**KawaiiPhysics** という別の無料プラグインが必要です。メインのプラグインには同梱されていないため、別途一度だけインストールします：

1. [KawaiiPhysicsのGitHubプロジェクトページ](https://github.com/pafuhana1213/KawaiiPhysics)を開きます。
2. 同様にReleasesページから最新版の圧縮ファイルをダウンロードします。
3. ステップ2と全く同じ方法で、プロジェクトのPluginsフォルダに入れます。

終わると、Pluginsフォルダには `MMD2Unreal` と `KawaiiPhysics` の2つのフォルダがあるはずです。

## ステップ4：プロジェクトを開いてプラグインを有効化する（通常は初期状態で有効）

1. `.uproject` ファイルをダブルクリックして、普段どおりプロジェクトを開きます。
2. 上部メニューの **Edit** → **Plugins** を開くと一覧ウィンドウが出ます。
3. 検索ボックスに `MMD2Unreal` と入力し、チェックが入っていることを確認します（初回起動時には通常すでに有効です。有効ならこの手順は飛ばしてください）。
4. `Kawaii` を検索し、KawaiiPhysicsも同じように有効になっているか確認します。
5. 無効になっていた場合は有効化してから、プラグインを反映させるため **Unreal Editorを一度再起動**します。

## ステップ5：インストールできたか確認する

最も簡単な確認方法：

1. 任意の `.pmx` モデルファイルを用意します。
2. Unreal下部の**コンテンツブラウザ**（アセットのサムネイルが並ぶ領域）にドラッグします。
3. インポート設定ウィンドウが出れば準備完了です。[次章](02-モデルのインポート.md)の手順に沿って本番インポートをしてください。

## よくある問題

### 「再ビルド / コンパイル」を尋ねられたとき

初回ロード時には再ビルドやコンパイルを尋ねるウィンドウが出ることがあります。Unreal Engineとプラグインのバージョンが一致しているか確認してください。このマニュアルはUnreal Engine 5.8を前提としており、将来のバージョンでは違いが出る可能性があるため、バージョン番号に注意してください。

## 表示言語

インポートウィンドウは、MMDコミュニティで最もよく使われる3言語（簡体字中国語・English・日本語）に対応しています。Unrealエディタの表示言語に自動で追従し、プラグイン側での設定は不要です：

- エディタの言語は **Edit > Editor Preferences > Region & Language** で切り替えられます。インポートウィンドウもそれに追従します。すでに開いているウィンドウは言語が変わらないため、閉じてからファイルをドラッグし直してください。
- その他の地域の言語では、自動的に英語へフォールバックします。
