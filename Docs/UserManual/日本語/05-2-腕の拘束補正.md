# 05-2 腕の拘束補正

キャラクターモーションをインポートしたあと、腕や手が胴体・頭部・脚・反対側の腕を貫通する場合は、**腕の拘束補正**でその貫通を抑えられます。

> **お知らせ**：本マニュアルは中国語の原文（正式版）をもとにAIで翻訳したものです。表現が完全に正確ではない場合があります。

主に次のような状況を対象にします：

- 上腕や前腕が胴体に入り込む；
- 手が胸、首、頭部、脚に入り込む；
- 両腕を交差したときに互いを貫通する；
- 速い腕の動きで大きく体内に入り込む。

必要なときだけ腕の姿勢を避ける方向へ補正する機能で、元のモーションそのものを置き換えるものではありません。髪やスカートなどの物理解算の代わりでもありません。

## 初期状態で有効か

**キャラクター** PMX をインポートする場合、**Rig → 腕の拘束補正** は初期状態で有効です。

**シーン** PMX をインポートする場合は、通常キャラクターの腕補正が不要なため初期状態では無効です。

多くのキャラクターでは、まず初期値のまま有効にしてモーションを再生し、必要な場合だけ調整するのがおすすめです。

## 既にインポート済みのモデルで有効にする

古いバージョンでインポートしたモデルや、当時このノードが生成されていないモデルでは、PMX を再インポートします：

1. モデルを Reimport します。
2. **既存の Post Process AnimBP を上書き** を有効にします。
3. その下の **腕の拘束補正** が有効になっていることを確認します。
4. 再インポートを完了します。

**腕の拘束補正は Post Process AnimBP 上書きの付随オプションです。** **既存の Post Process AnimBP を上書き** が無効の場合、MMD2Unreal は既存 ABP を変更せず、この機能だけを後から追加することもありません。

## どこで調整するか

Content Browser で次のアセットを探します：

`ABP_Post_<モデル名>`

開いて **AnimGraph** に入り、**M2U Arm Constraint Correction（腕の拘束補正）** ノードを探します。自動生成されたグラフでは、MMD の姿勢処理のあと、KawaiiPhysics の前に配置されます。

周囲の自動生成ノードは、モデル固有の MMD 腕、追加ボーン、IK の関係を保つために必要です。通常は削除、バイパス、並べ替えをしないでください。

ノードの **Alpha** が全体の強さです：

- `1.0`：完全に有効；
- `0.0`：補正を無効；
- 中間値：全体の補正量を弱める。

通常は `1.0` のままで問題ありません。

## よく使うパラメータ

多くのモデルでは手動調整は不要です。特定のモーションで問題が出るときは、まず次の項目から調整してください。

| パラメータ | 初期値 | 役割 |
| --- | ---: | --- |
| **Contact Margin (cm)** | `0.8` | 腕の判定範囲と障害物表面の間に残す最小距離。大きいほど体から離れます。 |
| **Avoidance Soft Zone (cm)** | `0.65` | 完全な貫通の少し前から補正を徐々に始める範囲。小さいほど元のモーションを長く保ち、大きいほど早く避けます。 |
| **Crossing Guard Distance (cm)** | `32` | 1回の補正で肘や手首を元の位置から動かせる最大距離。速い動きや深い貫通で抜けてしまうときは最初に上げます。 |
| **Solver Iterations** | `4` | 1フレーム内の補正回数。通常は変更不要です。 |
| **Pose Preservation Weight** | `0.35` | 元の姿勢を保とうとする強さ。大きいほど通常のモーションが変わりにくくなります。 |
| **Max Elbow Bend (deg)** | `155°` | 補正時に許可する肘の最大曲げ量。肘の反転や過度な折り畳みを抑えます。 |
| **Upper Arm Probe Start** | `0.32` | 肩に近い上腕の一部を判定から外す割合。正常な肩と胴体の接続部分を貫通と誤判定しにくくします。 |
| **Hand Rotation Follow** | `0.0` | 手首の向きが回避結果にどれだけ追従するか。`0` が元の手の向きを最も保つため、通常は初期値がおすすめです。 |
| **Cross Arm Response Scale** | `0.65` | 左右の腕が互いに避ける強さ。小さいほど、元のモーションが交差するときに柔らかく譲ります。体との衝突補正には影響しません。 |
| **Cross Arm Soft Zone (cm)** | `3.0` | 反対側の腕との接触前から回避を徐々に始める距離。プローブが重なる付近の押し出し方向も滑らかにします。 |
| **Cross Arm Priority** | `0.2` | 接触時にどちらの元の腕ポーズを優先するか。`-1` から `1` の範囲で、負は左腕、`0` は均等、正は右腕を優先します。 |

左右の腕グループには **Upper Arm Radius / Forearm Radius / Hand Radius** もあります。これらはインポート時にモデルに合わせて自動設定されるため、通常は変更不要です。

手だけがまだ貫通しやすい場合は、該当側の **Hand Radius** を一度に `10～20%` 程度ずつ小さく増やしてください。急に大きくすると、体に近づく前から回避が始まりやすくなります。

## コリジョン項目

ノード上で判定の種類を個別に無効化できます：

- **Upper Arm Collision**：上腕；
- **Forearm Collision**：前腕；
- **Hand Collision**：手；
- **Cross Arm Collision**：左右の腕同士；
- **Neck Collision**：首；
- **Head Collision**：頭部；
- **Leg Collision**：脚。

初期設定は多くのキャラクターに適しています。問題の切り分け時に一時的に1項目だけ無効にするのは有効ですが、1つのモーションのために大きな判定範囲を常時無効化するのはおすすめしません。

## Debug Draw で判定範囲を見る

どの判定範囲が姿勢に影響しているか分からない場合は、ノードの **Debug Draw** を有効にします。

モーションの再生・スクラブ中に次の表示が出ます：

- **赤**：胴体、首、頭部、脚の実際の障害範囲；
- **黄**：回避が始まる外側の範囲；
- **オレンジ**：元のアニメーションの腕の経路；
- **緑**：補正後の上腕・前腕の判定範囲；
- **シアンの球**：手の判定範囲；
- **灰色の手の球**：Hand Collision が無効。

デバッグ表示は通常の深度判定を使うため、モデルの後ろにある部分は普通に隠れます。複数の角度から見ると空間関係を判断しやすくなります。

**Debug Draw Alpha** でデバッグ表示全体の透明度を変更できます。確認用の機能なので、最終作業では Debug Draw を無効にしてかまいません。

## よくある調整例

### ある位置で腕が急に貫通する

まず **Crossing Guard Distance** を上げます。

例：

`32 → 40 → 50`

速い動きや深い貫通が止まるまで段階的に上げてください。高すぎると元のモーションから大きく離れることがあるため、最初から最大値にしない方が安全です。

### 明確な貫通がないのに通常の動きまで変わる

次の順で試します：

1. **Pose Preservation Weight** を上げる（例：`0.35 → 0.45`）；
2. **Avoidance Soft Zone** を下げる（例：`0.65 → 0.4`）；
3. 主に肩付近で起きるなら **Upper Arm Probe Start** を少し上げる。

一度に1項目だけ変更し、再生して確認してください。

### 肘が曲がりすぎる、反転したように見える

**Max Elbow Bend** を下げます。

例：

`155° → 145°` または `135°`

同時に **Hand Rotation Follow = 0** を維持すると、前腕補正に手首が強く巻き込まれてねじれるのを抑えやすくなります。

### 手がまだ体に入る

**Debug Draw** を有効にし、まずシアンの Hand Sphere が保護したい手の範囲を十分覆っているか確認します。

球が明らかに小さい場合は、その側の **Hand Radius** を少しだけ上げます。球が十分大きいのに速い動きで抜ける場合は、さらに球を大きくするのではなく **Crossing Guard Distance** を上げてください。

### 腕を交差すると互いに貫通する

**Cross Arm Collision** が有効か確認してください。元のポーズが通常の左右順序を保っている間は、**Cross Arm Priority** に従って左右両方が互いに避けます。元のモーションが明確に腕を交差させる場合は、交差位置でこの回避を滑らかに弱め、揺れを避けながら元のモーションを優先します。腕と体の衝突補正は引き続き有効です。

## MMD IK と KawaiiPhysics との関係

腕の拘束補正は、モデル自身の MMD 姿勢関係が処理されたあと、KawaiiPhysics の前で動作します。

そのため：

- この機能のために MMD IK を無効にする必要はありません；
- 腕補正を有効にするだけなら KawaiiPhysics の再調整は不要です；
- 手首軸、肘軸、捩り、補助ボーンを追加したモデルでも、モデル自身の関係に従って更新されます；
- 補正ノード周辺に自動生成された変換ノードや MMD 制約ノードは削除しないでください。

有効・無効だけ比較したい場合は **Arm Constraint Correction → Alpha** を変更する方法が最も安全です。

## 知っておきたい制限

腕の拘束補正は、元のアニメーションをできるだけ保ちながら、一般的な自己貫通を減らすための機能です。

1フレームで腕が体の片側から反対側へ飛ぶような極端な動きや、元のモーション自体が大きく折り畳まれている場合は、**Crossing Guard Distance** を上げるか、モーションのキーを直接修正する必要があります。

また、別キャラクター同士のコリジョンは処理しません。
