# 07 Creating Motion with Rig

This chapter explains how to create motion for an MMD model from scratch in Unreal's Sequencer. The recommended workflow is to add one of the Control Rigs generated by this plugin — `CR_` or `CRMMD_` — to the character binding, then pose the model in the viewport and set keyframes.

If you already have a VMD motion and only want to correct it, see [08 Editing Existing Motion with Rig](08-edit-existing-motion-with-rig.md).

> **Recommended route:** Use `CR_ModelName` when you want to pose the whole body quickly and place the hands with IK. Use `CRMMD_ModelName` when you prefer the MMD-style workflow of rotating the upper arm, lower arm, and hand directly.

## Before You Start

- You have imported a PMX model as described in [Importing a Model](02-import-model.md).
- **Create Rig Binding** was enabled during model import. After import, the Content Browser should contain two Control Rig assets beginning with `CR_` and `CRMMD_` in the model folder.
- If those assets are missing, import another copy of the model with **Create Rig Binding** enabled. Use a new empty folder if necessary to avoid same-name protection.
- You have a level and an MMD character that can be placed in it.
- Because of Unreal's plugin security policy, the first use of a model's Rig may require one compilation. Open the two CR assets in the Rig folder, click **Compile**, then close them.

## 1. Create a Level Sequence and Add the Character

1. In the Content Browser, click **Add**, open the Cinematics category, and create a **Level Sequence**. Give it an easy-to-recognize name such as `Dance_Rig`.
2. Double-click the Level Sequence to open it in Sequencer.
3. Drag the MMD character from the Content Browser into the level, then drag the character from the World Outliner into Sequencer. You can also select the character and use Sequencer's **Actor to Sequencer** command; both methods have the same result.
4. Expand the character binding in Sequencer and make sure it contains the character's **Skeletal Mesh** track. Add the Control Rig to this character binding, not to a camera or another Actor.
5. Set the playback range at the top of Sequencer. If you want to work in MMD frame numbers, set the sequence display rate to **30 FPS**. Then 30 timeline frames equal one second in MMD. VMD export also uses MMD's 30 FPS time base.

## 2. Add a Control Rig to the Character

1. Select the character's **Skeletal Mesh** track and click **+ Track** on its right side.
2. Choose **Control Rig > Control Rig Classes**.
3. Select the `CR_ModelName` or `CRMMD_ModelName` that belongs to this model. Do not choose a Rig generated for another model; if the skeleton does not match, the Rig may not appear or may not drive the character correctly.
![Control Rig](../DocPic/Controlrig.jpg)
4. Sequencer adds a Control Rig track and a Control Rig section. Expand it to see the controls that can be animated. Selecting a control in the list also selects it in the viewport, and selecting a control in the viewport locates it in Sequencer.
5. If the controls are not visible, expand the Control Rig track and select one control, then move the viewport focus to the character. Also check that the eye icon on the track has not hidden the Rig.

### Choosing Between `CR_` and `CRMMD_`

| Rig asset | Editing style | Common controls | Recommendation |
|---|---|---|---|
| `CR_ModelName` | Quickly pose limbs with IK | `CTRL_HandIK_L/R`, `CTRL_ElbowPole_L/R`, `CTRL_LegIK_L/R`, `CTRL_Toe_L/R` | Prefer it for new dances, walks, and standing poses |
| `CRMMD_ModelName` | Rotate MMD-style FK segments directly | `CTRL_UpperArm_L/R`, `CTRL_LowerArm_L/R`, `CTRL_Hand_L/R` | Use it when you want precise segment-by-segment arm control or are used to MMD |

Both Rigs include body, head, eye, finger, leg/foot, and face controls. Controls on the left and right sides usually end in `_L` and `_R`.

The automatic binding algorithm for these model controllers is the result of substantial work by `RedialC`. If you use this Rig to produce motion data and find it useful, please credit the tool so more people can discover this modern MMD keyframing workflow.

For more information about setting keyframes in Sequencer, see additional Unreal Engine video tutorials or the official documentation. Everyone may develop their own workflow; the later sections of this manual also explain the basics without going into excessive detail.

## 3. Set Keyframes Freely on the Timeline

### 1. Make the starting pose

1. Move the playhead to the first motion frame, normally frame 0.
2. Select the controls you want in the viewport and pose them with the Move or Rotate tool. You can also enter values directly in Sequencer or the Details panel.
3. Multi-select controls that should be recorded together, such as the torso, both hands, and both feet.
4. For transform controls, press `S` or click the key button in Sequencer to add a keyframe. The control's channels and keys will appear below the track.

### 2. Change the pose on later frames

1. Move the playhead to the next important pose, such as frame 15, 30, or 45.
2. Move or rotate the controls, then press `S` or click the key button again.
3. Continue moving the playhead, changing controls, and setting keys. Sequencer interpolates between neighboring keys: fewer keys give smoother motion, while more keys make it easier to hold exact poses.
4. To hold a pose, key the relevant controls at both the start and end of the hold instead of keying only the first frame.
5. When editing a group of controls together, select them all before setting the key. This prevents the torso, hands, and feet from being keyed inconsistently.

### 3. Practical arm and leg editing

- With `CR_`, move `CTRL_HandIK_L/R` to place the hands, then move `CTRL_ElbowPole_L/R` to guide the elbows, and finally rotate the hand controls. If an elbow suddenly flips to the other side, the Pole control usually needs to be repositioned.
- With `CRMMD_`, rotate `CTRL_UpperArm_*`, `CTRL_LowerArm_*`, and `CTRL_Hand_*` in the order upper arm, lower arm, then hand. This is closer to rotating MMD's upper-arm, lower-arm, and wrist bones directly.
- Use `CTRL_LegIK_L/R` to place the feet, `CTRL_LegAngle_L/R` to adjust the leg direction, and `CTRL_Toe_L/R` to adjust the toes. When the soles need to stay on the floor, solve the foot position before adjusting the toes.
- `CTRL_Root`, `CTRL_Center`, `CTRL_Groove`, and `CTRL_Pelvis` control overall position, body weight, and the pelvis. For a pose-only change, rotate torso controls first; move Root or Center only when the character should travel through the scene.

## 4. Fingers, Eyes, and Expressions

- Finger controls look like `CTRL_Thumb_1_L` or `CTRL_Index_1_R`. They are numbered from the base toward the fingertip. Selecting several controls on the same hand before setting a key makes it easier to keep a consistent hand shape.
- Use `CTRL_Eye_L` and `CTRL_Eye_R` to aim the eyes. Pose the gaze on one frame, then change it and key it on later frames to make the character look at different points.
- Face controls begin with `CTRL_Face_` and are grouped into areas such as eyes, mouth, and brows. Select a face slider, adjust it, and click the key button next to its channel in Sequencer. Face controls usually use values from 0 to 1. Key the same value at the beginning and end when an expression should hold.
- PMX models can have different expression counts and Japanese names. If an expression is not immediately visible, expand the relevant face group; do not edit the Rig asset directly.

## 5. Adjust Keys and Curves

1. Expand the Control Rig track and locate a control's translation, rotation, or expression channel.
2. Drag keys in the timeline to change when they happen. Open Curve Editor to adjust interpolation and tangents for smoother starts and stops.
3. If the character jitters around a key, first check whether neighboring rotations jump too far. Move the key or edit the curve before considering larger changes; do not delete the entire Control Rig track to fix one pose.
4. Control keys are stored in the Level Sequence. `CR_` and `CRMMD_` only define the controls and how they solve the skeleton. Save the sequence to keep the motion; there is no need to save or modify the Rig asset.

## 6. Preview and Save

1. Scrub across the important keys, then press Play to watch the complete motion.
2. Check for flipped arms or legs, feet going through the floor, fingers failing to follow the hands, and eyes or expressions changing on the intended frames.
3. Hair, skirts, and similar dynamic physics are calculated live when the scene plays. Do not try to key physics effects manually.
4. Save the Level Sequence. When you want to take the final motion back to MMD, continue with [09 Exporting Character Motion VMD](09-export-motion.md); the exporter reads the character's final motion and expressions from Sequencer.

## Common Problems

### `CR_` or `CRMMD_` cannot be selected

Make sure the character uses the Skeletal Mesh imported by this plugin and that **Create Rig Binding** was enabled. Also make sure the Control Rig asset has finished loading. If the model was just imported, wait for the Content Browser to refresh and reopen the Level Sequence.

### The character jumps to a strange pose after the Rig is added

You may have selected a Rig from another model or added it to the wrong character binding. Delete the Control Rig section, then add the matching `CR_` or `CRMMD_` under this character's Skeletal Mesh track.

### Keys are present but playback does not change

Make sure you are editing the Control Rig controls added to Sequencer, not the Rig asset opened from the Content Browser. Check that the controls are visible and that the playhead is inside the Control Rig section's range.

### How do I export this motion?

You do not need to convert the controls to a bone animation by hand. Save the Level Sequence, then choose the current Sequencer as the source in [Exporting Character Motion VMD](09-export-motion.md).
