# 03 模型姿态与物理调优

本章介绍模型导入后的两个检查点：先确认模型的初始姿态，再检查头发、裙摆、袖子等部位的物理效果。

## 本章的适用条件

本章中的 KawaiiPhysics 节点和碰撞资产，只有在[导入模型](02-导入模型.md)时勾选 **启用物理** 后才会生成。导入完成后，通常可以在 Content Browser 中找到：

| 资产 | 作用 |
| --- | --- |
| `ABP_Post_<模型名>` | 后处理 Animation Blueprint（动画蓝图），在输入动画之后追加 MMD 的 IK/追加变形和 KawaiiPhysics 物理。 |
| `Phy/PA_<模型名>_ALL` | 包含模型全部可用 MMD 碰撞体的 Physics Asset，KawaiiPhysics 默认使用它。 |
| `Phy/PA_<模型名>_G00`、`_G01` … | 按 MMD 碰撞组拆分的 Physics Asset，用于检查或手动选择特定碰撞组。实际生成哪些编号取决于 PMX 模型。 |
| `IKR_<模型名>` | IK Rig 资产，用于角色重定向或其他 IK 工作流；它与 `ABP_Post` 中的 IK/约束节点不是同一个东西。 |

如果这些物理资产不存在，请检查：

1. 导入模型时是否勾选了 **启用物理**。
2. 项目是否启用了 KawaiiPhysics 插件。
3. PMX 是否包含有效的物理刚体和动态骨骼链。

已经在未勾选物理的情况下导入模型时，建议重新导入 PMX，并勾选 **启用物理**。如果项目中已有同名资产，可先导入到新的内容目录，避免把正在使用的资产混淆。

## ABP 的作用

`ABP_Post_<模型名>` 是模型的后处理动画蓝图。它不负责替代 VMD 或 Sequencer 中的基础动画，而是在基础动画已经计算出来之后，对最终骨骼姿态追加一层处理：

```text
输入动画 → MMD IK/追加变形 → KawaiiPhysics → 输出到模型
```

因此，Sequencer 中的 VMD、Control Rig 和其他动画仍然是姿态的主要来源；ABP 负责把 MMD 模型自身的约束和物理效果叠加到最终姿态上。播放或预览时，头发、裙摆等动态骨骼会根据当前姿态和模型移动重新计算。

导入时不勾选 **启用物理**，插件仍可能创建用于 MMD IK/追加变形的 `ABP_Post`，但不会创建本章所需的 KawaiiPhysics 节点和按碰撞组生成的物理资产。因此，这种情况下不能通过本章的方法调节 MMD 物理。

## ABP 中 IK 节点的功能

ABP 中的 MMD IK/约束节点会读取 PMX 中定义的 IK 链、目标骨骼、链接骨骼以及限制角度，并在基础动画之后重新求解。例如，它可以帮助脚部、膝盖、手臂等骨骼保持模型作者在 PMX 中定义的结构关系；同时也会处理 MMD 的追加旋转或追加位移。

引入自动化算法，大多数情况下不需要像MMD那样单独调节每个IK通道是否开启，但还是需要说明**IK节点上的对应IK数值就是对应MMD中IK通道的开关。**

绝大部分情况下不需要改动 ABP 内的 IK 节点。原因是：

- 每个模型的骨骼名称、IK 链和限制角度都不同，节点是根据当前 PMX 自动生成的。
- 修改 IK 链、目标骨骼或执行顺序，可能导致膝盖反向、脚部漂移、手臂翻转或动作与 MMD 不一致。
- 物理碰撞问题通常应通过 Physics Asset 和 KawaiiPhysics 节点的参数解决，而不是通过修改 IK 节点“硬拽”骨骼。

只有在你明确了解 PMX 骨骼约束，并且确实要制作自定义动画管线时，才建议复制一份 ABP 后进行实验。正常使用时，保持自动生成的 IK/约束节点和连接顺序即可。

## 使用 KawaiiPhysics 改善物理效果

### 1. 先用默认配置观察问题

在 Content Browser 中找到 `ABP_Post_<模型名>`，打开它的 AnimGraph。启用物理后，图表中会有自动生成的 KawaiiPhysics 节点，通常位于带有 `PMX Kawaii Physics (MMD2Unreal Generated)` 标记的区域。

先不要修改 IK 节点。打开一个包含该模型的 Level Sequence，播放一小段动作，分别观察：

- 头发是否穿过头部或肩膀；
- 裙摆是否穿过腿部；
- 袖子、领带或配饰是否抖动过大；
- 模型快速转身或移动时，动态骨骼是否突然拉长、爆开或停滞。

先确认问题属于“碰撞体不合适”还是“物理参数不合适”，再做一次小幅修改并重新预览。

### 2. 在 KawaiiPhysics 节点选择 MMD 碰撞组
![KawaiiPhysics 节点](DocPic/Abp_View.jpg)

这是选择对应 MMD 碰撞组的入口：

1. 打开 `ABP_Post_<模型名>`，切换到 **AnimGraph**。
2. 单击要调节的 KawaiiPhysics 节点。
3. 在右侧 **Details** 面板展开 **Limits**。
4. 在 **Physics Asset** 属性中选择 `PA_<模型名>_ALL` 或 `PA_<模型名>_Gxx`。
5. 点击工具栏 **Compile**，保存 ABP，再回到 Level Sequence 预览。

`Gxx` 中的 `xx` 就是 PMX 刚体的 MMD 碰撞组编号，编号范围为 `00` 到 `15`。例如：

| MMD 碰撞组 | 对应资产 |
| --- | --- |
| 组 0 | `PA_<模型名>_G00` |
| 组 1 | `PA_<模型名>_G01` |
| 组 2 | `PA_<模型名>_G02` |
| … | … |
| 组 15 | `PA_<模型名>_G15` |

![碰撞组选择](DocPic/collision_change.jpg)
默认建议使用 `_ALL`。它包含所有有效的 MMD 碰撞体，并且导入器已经把 PMX 的双向不碰撞遮罩写入 Physics Asset。只有在需要隔离某个碰撞组、比较不同组的效果，或模型的某条动态链明显被不相关碰撞体干扰时，才将 KawaiiPhysics 节点的 **Physics Asset** 换成对应的 `_Gxx` 资产。

这里选择的是“碰撞体的来源”，不是选择哪一条头发或裙摆骨骼进行模拟。模拟骨骼仍由该 KawaiiPhysics 节点的 `Root Bone` 和 `Additional Root Bones` 决定。一个 ABP 可能有多个 KawaiiPhysics 节点；需要单独处理时，可以分别为节点指定碰撞资产。

### 3. 检查和调整碰撞形状

双击 `PA_<模型名>_ALL` 或某个 `_Gxx` 资产，打开 Physics Asset Editor：

1. 确认预览网格是当前 MMD 模型。
2. 打开碰撞显示，检查身体、头部、肩膀和腿部的球体、胶囊体或盒体是否位于正确位置。
3. 如果碰撞体明显偏离模型，优先检查模型导入、骨骼姿态和缩放；不要先通过放大 KawaiiPhysics 的 `Radius` 来补偿整体偏移。
4. 需要修正形状时，调整对应 Body 的位置、旋转或尺寸，然后保存 Physics Asset。
5. 回到 ABP 和 Level Sequence 播放验证。只改动一个区域，便于判断是哪项设置产生了效果。

MMD 的碰撞刚体会被导入为 Physics Asset 中的碰撞形状。`_ALL` 和 `_Gxx` 是由同一 PMX 数据生成的不同碰撞资产；重新导入模型时，相关生成资产可能会重新生成，因此建议把自定义调节记录下来。

### 4. 调整 KawaiiPhysics 的基础参数

仍然在 KawaiiPhysics 节点的 Details 面板中，展开 **Physics Settings**：

| 参数 | 调整方向 |
| --- | --- |
| `Damping` | 越小越容易摆动，越大越快变得迟钝、沉重。头发完全不动时可适当减小；抖动持续太久时可适当增大。 |
| `Stiffness` | 越大越倾向于回到动画原姿态，越小越自由。裙摆被动作甩飞时通常应适当增加；想要更柔软的摆动时可适当降低。 |
| `Radius` / `Collision Radius` | 动态骨骼自身用于推开碰撞体的半径。过大容易造成爆开或相互挤压，过小则容易穿透。 |
| `Limit Angle` | 限制单步物理旋转幅度，可抑制突然翻转和抖动。`0` 表示不限制；出现异常旋转时可设置一个合理的正值。 |
| `World Damping Location`、`World Damping Rotation` | 控制模型整体移动、旋转对摆动的传递。模型快速移动时动态骨骼甩动过强，可适当提高；希望有明显拖尾时再降低。 |

建议每次只调整一个参数，并以小幅度反复预览。不同模型的骨骼长度、刚体大小和动作幅度差异很大，不能把某个模型的数值直接套到另一个模型上。

### 5. 针对裙摆穿透的处理

裙摆穿透通常由“碰撞体太小、碰撞组不正确、相邻动态骨骼间距过大”中的一项或多项造成。可以按以下顺序处理：

1. 先恢复或选择 `PA_<模型名>_ALL`，确认裙摆能检测到身体和腿部碰撞体。
2. 在 Physics Asset Editor 中适当扩大腿部、臀部或身体碰撞体，但不要让碰撞体大幅穿出模型表面。
3. 在 KawaiiPhysics 节点中略微增加 `Radius`。
4. 如果相邻裙摆骨骼之间有明显空隙，可在 **Bones → Bone Subdivision** 中增加 `Bone Subdivision Count`，提高长骨段之间的碰撞检测密度；这会增加计算量。
5. 仍然穿透时，再检查该裙摆动态链是否应该使用另一个 `Gxx` 碰撞组，并确认 PMX 的不碰撞遮罩没有禁止这对碰撞。

相反，如果裙摆被身体“弹飞”，先减小 `Radius` 或碰撞体尺寸，再检查是否误选了包含过多身体部位的碰撞组。

## 不建议直接修改的内容

- 不要为了修复穿透而随意删除或重排 ABP 中的 MMD IK/约束节点。
- 不要同时用同一批碰撞体填充 Physics Asset 和 KawaiiPhysics 节点的 `Spherical Limits`、`Capsule Limits`、`Box Limits`，否则可能产生重复碰撞。
- 不要一次修改多个动态链、多个 Physics Asset 和全部物理参数；很难定位问题来源。
- 重新导入模型后应重新确认 ABP 中的 Physics Asset 是否仍然指向预期的 `_ALL` 或 `_Gxx` 资产。

KawaiiPhysics 的碰撞形状、参数、骨骼细分、曲线和外力还有更多用法，请参考[KawaiiPhysics 官方碰撞设置文档](https://pafuhana1213.github.io/KawaiiPhysics-Portal/en/docs/features/collision-setup)以及[官方参数参考](https://pafuhana1213.github.io/KawaiiPhysics-Portal/en/docs/parameters/physics)。

模型姿态和物理确认完成后，可以继续[04 M2U 材质调节](04-M2U材质调节.md)。
