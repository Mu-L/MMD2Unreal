# 01 下载与安装

这一章带你完成三件事：下载插件、把它放进你的项目、确认它能正常工作。全程大约五分钟。


## 你需要准备什么


- 已经装好的 Unreal Engine 5.8
- 一个已经创建好的 Unreal 项目（空白项目就可以）
- 能正常访问 GitHub 的网络

## 第一步：下载插件

1. 打开插件的 GitHub 项目主页。
2. 在主页右侧找到 **Releases**（发布版本）入口，点进去。
3. 版本按时间排列，最上面的那个标着 **Latest** 的就是最新版。直接用它即可，不需要纠结具体版本号。
4. 在最新版的页面下方找到附件区域（Assets），下载里面的压缩包文件（通常是 `.zip` 结尾）。
5. 下载完成后，记住这个压缩包放在哪里。

## 第二步：选择并安装对应版本

- **Win64 普通版**：适用于蓝图项目和大多数用户。解压后按下面步骤放进项目的 `Plugins` 文件夹。
- **C++ 工程版**：适用于 C++ 项目。请解压到 `UE_5.8/Engine/Plugins/Marketplace/MMD2Unreal`，并删除项目 `Plugins` 目录中旧的 `MMD2Unreal` 文件夹，避免项目插件覆盖引擎安装。

### Win64 普通版：放进项目

1. 在电脑上找到你的 Unreal 项目文件夹。判断方法：这个文件夹里有一个和你项目同名的、以 `.uproject` 结尾的文件。
2. 看看文件夹里有没有一个叫 **Plugins** 的文件夹。没有的话，自己新建一个，名字必须一字不差。
3. 把第一步下载的压缩包解压，把解压出来的插件文件夹整个放进 Plugins 里面。
4. 放好之后检查一下：插件文件夹里应该能直接找到一个叫 `MMD2Unreal.uplugin` 的文件，也就是完整路径形如 `你的项目/Plugins/MMD2Unreal/MMD2Unreal.uplugin`。如果你点进去一层又是一个同名文件夹，就把里面那层移上来。

## 第三步：安装物理效果组件（必须）

模型导入后的头发飘动、裙摆摇摆这类效果，依赖另一个免费的插件 **KawaiiPhysics**。主插件本身不带它，所以需要单独装一次：

1. 打开 [KawaiiPhysics 的 GitHub 项目主页](https://github.com/pafuhana1213/KawaiiPhysics)。
2. 同样进入 Releases 页面，下载最新版的压缩包。
3. 用和第二步完全相同的方法，把它也放进项目的 Plugins 文件夹。

装完之后，你的 Plugins 文件夹里应该有两个文件夹：`MMD2Unreal` 和 `KawaiiPhysics`。

## 第四步：打开项目并启用插件（通常默认启用）

1. 双击 `.uproject` 文件，像平常一样打开项目。
2. 打开后，点击顶部菜单的 **编辑**，选择 **插件**，会弹出一个列表窗口。
3. 在搜索框输入 `MMD2Unreal`，确认它的勾选框是勾上的（通常第一次打开时就是开启，如果是开启的则跳过）。
4. 再搜索 `Kawaii`，用同样的方法确认 KawaiiPhysics 也已启用。
5. 如果没有开启的话，点击开启后 **重启一次 Unreal Editor**，让两个插件生效。

## 第五步：确认安装成功

最简单的检验方法：

1. 准备一个 `.pmx` 模型文件。
2. 把它直接拖进 Unreal 底部的**内容浏览器**（就是平时显示资产缩略图的那块区域）。
3. 如果弹出了一个导入设置窗口，恭喜，一切就绪。按照[下一章](02-导入模型.md)的指引正式导入。

## 常见问题

### 如果打开项目时提示需要编译

第一次加载插件时，可能会弹出一个问你是否"重建"或"编译"的窗口。需要检查UE和插件的版本是否是一致的(手册按照5.8来介绍,未来可能会有版本的不同,需要留意版本号细节)。

## 界面语言

插件的导入窗口支持 MMD 社区中最常见的三种语言：简体中文、English、日本語。它会自动跟随 Unreal 编辑器的显示语言，不需要在插件里做任何设置：

- 在 **编辑 > 编辑器偏好设置 > 地区与语言** 中切换编辑器语言，导入窗口就会跟着变；已经打开的导入窗口需要关掉、重新拖一次文件才会换语言。
- 使用其他地区语言的用户会自动回退到英文显示。
